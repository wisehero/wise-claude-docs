# 반복 작업 자동화

> **난이도**: 중급 | **선행 문서**: [외부 도구 연동](04-외부-도구-연동.md) | **최초 작성**: 2026-04-13 | **마지막 수정**: 2026-04-13
>
> 매일 반복되는 업무를 Cowork가 알아서 처리하도록 자동화하는 방법을 다룬다. 스킬 설정부터 예약 작업, 모바일 원격 지시까지.

---

## 왜 자동화인가?

지식 노동의 상당 부분은 반복이다. 아침마다 이메일을 훑어 중요한 내용을 추리고, 매주 금요일 팀 보고서를 만들고, 다운로드 폴더에 쌓인 파일을 정리하고, 경쟁사 뉴스를 모니터링한다. 하나하나는 어렵지 않지만, 매번 수작업으로 하면 하루에 1~2시간이 사라진다.

Cowork의 자동화는 이런 반복 작업을 대신 처리해 준다.

| 수작업 | Cowork 자동화 |
|--------|---------------|
| 매일 아침 이메일 30개를 읽고 핵심만 정리 | 출근하면 브리핑 문서가 이미 준비되어 있음 |
| 금요일 오후 각 팀 폴더를 돌며 현황 취합 | 4시에 자동으로 주간 보고서 생성 |
| 뉴스 사이트를 돌아다니며 기사 수집 | 매일 산업 뉴스 요약이 Excel로 정리됨 |
| 다운로드 폴더를 열고 하나씩 분류 | 매주 자동으로 날짜별 정리 완료 |

자동화의 핵심은 세 가지다.

1. **스킬(Skills)**: Cowork가 할 수 있는 개별 능력
2. **플러그인(Plugins)**: 스킬 + 외부 도구 연결 + 서브 에이전트를 묶은 패키지
3. **예약 작업(Scheduled Tasks)**: 특정 시간에 자동으로 실행되는 지시

이 세 가지를 조합하면, "매주 금요일 4시에 Google Drive에서 데이터를 가져와 보고서를 만들어 이메일로 보내줘" 같은 복합 자동화가 가능해진다.

---

## 스킬(Skills) 이해하기

스킬은 Cowork가 갖고 있는 **개별 능력**이다. 사람으로 치면 "엑셀을 다룰 줄 안다", "PPT를 만들 줄 안다"에 해당한다.

### 기본 제공 스킬

Cowork에는 Anthropic이 미리 만들어 놓은 스킬이 포함되어 있다. 별도 설치 없이 바로 사용할 수 있다.

| 스킬 | 할 수 있는 일 |
|------|---------------|
| Excel | 스프레드시트 생성, 데이터 분석, 차트 만들기, 피벗 테이블 |
| Word | 문서 작성, 서식 지정, 표 삽입 |
| PowerPoint | 프레젠테이션 생성, 슬라이드 디자인, 차트 삽입 |
| PDF | PDF 읽기, 데이터 추출, PDF 생성 |

### 스킬 확인하는 방법

현재 사용 가능한 스킬 목록은 다음 경로에서 확인한다.

1. 좌측 사이드바에서 **Customize**(사용자 설정)를 클릭한다
2. **Skills** 탭을 선택한다
3. 활성화된 스킬과 설명이 표시된다

스킬은 켜고 끌 수 있다. 사용하지 않는 스킬은 비활성화하면 Cowork가 불필요한 동작을 시도하지 않는다.

### 스킬이 작동하는 방식

사용자가 "이 데이터로 엑셀 파일 만들어줘"라고 요청하면, Cowork는 자동으로 Excel 스킬을 호출한다. 별도로 "Excel 스킬을 사용해"라고 지정할 필요가 없다. 요청의 맥락에서 어떤 스킬이 필요한지 Cowork가 판단한다.

## 커스텀 스킬 만들기

기본 스킬만으로 부족할 때, 나만의 스킬을 만들 수 있다. 코딩은 필요 없다. Cowork가 인터뷰 형식으로 질문하고, 답변을 바탕으로 스킬을 자동 생성한다.

### `/skill-creator` 명령어

대화창에 `/skill-creator`를 입력하면 스킬 생성 모드가 시작된다. Cowork가 다음과 같은 질문을 순서대로 던진다.

1. "어떤 작업을 자동화하고 싶으신가요?"
2. "입력 데이터는 어디서 가져오나요?" (폴더, 이메일, 특정 앱 등)
3. "결과물은 어떤 형태여야 하나요?" (문서, 스프레드시트, 이메일 등)
4. "특별한 규칙이나 조건이 있나요?"

답변을 마치면 Cowork가 스킬을 생성하고 테스트 실행까지 진행한다.

### 실전 예시: "주간 보고서 생성" 스킬

마케팅 팀에서 매주 금요일 각 채널의 성과를 정리한 주간 보고서를 만든다고 가정하자.

**1단계**: `/skill-creator` 입력

**2단계**: Cowork의 질문에 답변

```
Q: 어떤 작업을 자동화하고 싶으신가요?
A: 매주 마케팅 채널별 성과를 정리한 주간 보고서를 만들고 싶어

Q: 입력 데이터는 어디서 가져오나요?
A: Google Drive의 '마케팅 데이터' 폴더에 채널별 CSV 파일이 있어

Q: 결과물은 어떤 형태여야 하나요?
A: PPT 형식. 첫 페이지에 요약, 이후 채널별 상세 데이터와 차트

Q: 특별한 규칙이나 조건이 있나요?
A: 전주 대비 증감률을 반드시 표시해줘. 목표 대비 달성률이 80% 미만인
   항목은 빨간색으로 강조
```

**3단계**: Cowork가 스킬을 생성하고 샘플 데이터로 테스트 실행

**4단계**: 결과를 확인하고 필요하면 수정 요청

```
보고서 첫 페이지에 핵심 지표 3개(총 방문자, 전환율, 비용)를 
큰 숫자로 보여주는 대시보드 형태로 바꿔줘
```

### 스킬 작성 모범 사례

| 원칙 | 설명 | 예시 |
|------|------|------|
| 하나의 스킬, 하나의 워크플로우 | 한 스킬이 너무 많은 일을 하면 결과가 불안정해진다 | "보고서 생성"과 "이메일 발송"은 별도 스킬로 |
| 명확한 설명 | 스킬 이름과 설명을 구체적으로 작성한다 | "주간 마케팅 보고서 생성 — Google Drive CSV 데이터 기반" |
| 예시 포함 | 원하는 결과물의 예시를 함께 제공한다 | "출력 형식은 첨부한 샘플 PPT와 동일하게" |
| 점진적 개선 | 처음부터 완벽하게 만들려 하지 말고, 실행 후 피드백으로 개선한다 | 첫 버전 실행 → 수정 요청 → 반복 |

## 플러그인 활용하기

플러그인은 스킬보다 한 단계 큰 개념이다. 스킬(개별 능력) + 커넥터(외부 도구 연결) + 서브 에이전트(보조 작업자)를 하나로 묶은 패키지다.

### 직군별 플러그인

Anthropic과 서드파티에서 제공하는 직군별 플러그인이 있다.

| 직군 | 플러그인 예시 | 주요 기능 |
|------|---------------|-----------|
| 영업(Sales) | CRM 연동, 파이프라인 분석, 제안서 자동 생성 | Salesforce/HubSpot 데이터 접근 |
| 재무(Finance) | 재무제표 분석, 예산 추적, 인보이스 처리 | 회계 소프트웨어 연동 |
| 법무(Legal) | 계약서 검토, 규정 준수 점검, NDA 분석 | 법률 문서 파싱 특화 |
| 마케팅(Marketing) | 캠페인 분석, 콘텐츠 생성, SEO 최적화 | 광고 플랫폼 데이터 연동 |
| HR/인사 | 이력서 분석, 설문 결과 정리, 온보딩 자료 생성 | 채용 플랫폼 연동 |
| 엔지니어링(Engineering) | 코드 리뷰, 배포 모니터링, 기술 문서 생성 | GitHub/Jira 연동 |
| 디자인(Design) | 에셋 정리, 디자인 가이드 생성, 피드백 수집 | Figma 연동 |
| 운영(Operations) | 워크플로우 자동화, 재고 관리, 일정 조율 | 프로젝트 관리 도구 연동 |
| 데이터 분석(Data Analysis) | 데이터셋 정리, 시각화, 통계 분석 | BI 도구 연동 |

### 플러그인 설치 방법

1. 좌측 사이드바에서 **Customize**를 클릭한다
2. **Browse plugins**를 선택한다
3. 카테고리별로 탐색하거나 검색어를 입력한다
4. 원하는 플러그인의 **Install** 버튼을 클릭한다

설치 후 해당 플러그인이 필요한 외부 서비스(예: Google Drive, Slack) 인증을 요구할 수 있다. 화면 안내에 따라 계정을 연결하면 된다.

### 기업 환경에서의 플러그인 관리

기업(Enterprise) 요금제에서는 관리자가 조직 전체에 플러그인을 배포하고 관리할 수 있다.

- **관리자 배포**: IT 관리자가 승인한 플러그인만 직원에게 제공
- **권한 제어**: 플러그인별로 접근 가능한 데이터 범위 설정
- **일괄 설정**: 신규 직원에게 직군에 맞는 플러그인 자동 할당

## 예약 작업 설정

예약 작업은 Cowork 자동화의 핵심이다. "매일 아침 8시에 이 작업을 해줘"처럼 시간을 정해두면, Cowork가 자동으로 실행한다.

### 예약 작업 만들기

두 가지 방법이 있다.

**방법 1: `/schedule` 명령어**

대화창에 `/schedule`을 입력하면 예약 작업 설정 화면이 열린다.

**방법 2: 사이드바에서 직접 생성**

1. 좌측 사이드바에서 **Scheduled tasks**(예약 작업)를 클릭한다
2. **+ New task** 버튼을 클릭한다
3. 작업 내용, 실행 주기, 시작 시간을 설정한다

### 실행 주기 옵션

| 주기 | 설명 | 사용 예시 |
|------|------|-----------|
| Hourly (매시간) | 1시간마다 실행 | 실시간 뉴스 모니터링 |
| Daily (매일) | 매일 지정한 시간에 실행 | 아침 브리핑 |
| Weekdays (평일만) | 월~금에만 실행 | 업무용 일일 보고 |
| Weekly (매주) | 매주 지정한 요일, 시간에 실행 | 주간 보고서 |
| Manually (수동) | 자동 실행 없음, 직접 트리거할 때만 실행 | 비정기 작업 |

### 반드시 알아야 할 조건

예약 작업이 실행되려면 두 가지 조건이 **동시에** 충족되어야 한다.

1. **컴퓨터가 켜져 있어야 한다** (잠자기 모드도 안 됨)
2. **Claude Desktop이 실행 중이어야 한다**

이 두 조건 중 하나라도 충족되지 않으면 예약된 작업은 **건너뛴다**. 하지만 걱정할 필요는 없다. 조건이 다시 충족되면 밀린 작업이 자동으로 실행된다.

> **실전 팁**: 회사 컴퓨터를 퇴근할 때 끄는 습관이 있다면, 아침 브리핑 같은 예약 작업은 출근 시간 이후(예: 오전 9시)로 설정하는 것이 안전하다. 컴퓨터를 켜고 Claude Desktop을 실행하면 밀린 작업이 바로 시작된다.

### 실전 예시: 아침 브리핑 (매일 오전 8시)

```
Gmail과 Slack에서 오늘 아침까지 온 중요 메시지를 요약하고,
오늘 캘린더 일정과 함께 브리핑 문서를 만들어줘.

형식:
1. 긴급 메시지 (답장이 필요한 것)
2. 참고용 메시지 (읽어두면 좋은 것)
3. 오늘 일정 (시간순)
4. 오늘의 할 일 제안
```

**설정 방법**:
- 주기: Daily
- 시간: 오전 8:00
- 출력: Word 문서로 바탕화면에 저장

출근해서 컴퓨터를 켜면 바탕화면에 오늘의 브리핑 문서가 준비되어 있다.

### 실전 예시: 주간 보고서 (매주 금요일 오후 4시)

```
이번 주 Google Drive의 '프로젝트 현황' 폴더에서 업데이트된 파일을
확인하고, 팀별 진행 상황을 정리한 주간 보고서를 만들어줘.

포함할 내용:
- 각 팀의 이번 주 완료 항목
- 다음 주 계획
- 지연되고 있는 항목 (빨간색 강조)
- 전체 프로젝트 진행률 차트

형식: PowerPoint, 10장 이내
```

**설정 방법**:
- 주기: Weekly
- 요일: 금요일
- 시간: 오후 4:00
- 출력: PPT 파일로 지정 폴더에 저장

금요일 오후 퇴근 전에 보고서가 자동으로 만들어져 있으니, 확인만 하고 팀에 공유하면 된다.

### 실전 예시: 뉴스 모니터링 (매일)

```
우리 산업 관련 뉴스를 검색하고, 경쟁사 동향 3건을 정리해서 Excel로 만들어줘.

검색 키워드: [산업명], [경쟁사A], [경쟁사B], [경쟁사C]

Excel 형식:
| 날짜 | 출처 | 제목 | 요약 (2줄) | 중요도 (상/중/하) | 링크 |

시트를 나눠서:
- 시트1: 오늘의 주요 뉴스
- 시트2: 경쟁사별 동향
- 시트3: 이번 주 누적 (기존 파일에 추가)
```

**설정 방법**:
- 주기: Weekdays (평일만)
- 시간: 오전 9:00
- 출력: Excel 파일로 지정 폴더에 저장 (매일 같은 파일에 시트 추가)

### 실전 예시: 파일 정리 (매주)

```
다운로드 폴더에서 7일 이상 된 파일을 날짜별로 분류하고 정리해줘.

규칙:
- 이미지 파일 (.jpg, .png, .gif) → '사진' 폴더의 연-월 하위 폴더로 이동
- 문서 파일 (.pdf, .docx, .xlsx) → '문서' 폴더의 연-월 하위 폴더로 이동
- 설치 파일 (.dmg, .exe, .pkg) → 휴지통으로 이동
- 나머지 → '기타' 폴더로 이동
- 완료 후 정리 결과를 간단한 텍스트 파일로 남겨줘
```

**설정 방법**:
- 주기: Weekly
- 요일: 일요일
- 시간: 오전 10:00

## Dispatch — 모바일에서 업무 지시

Dispatch는 스마트폰에서 업무를 지시하고, 컴퓨터의 Cowork가 실행한 뒤, 결과를 다시 스마트폰에서 확인하는 기능이다.

### 어떤 상황에서 쓰나?

출퇴근길 지하철 안에서 "오늘 회의 자료 준비해줘"라고 스마트폰에 입력한다. 사무실에 도착하면 컴퓨터에 회의 자료가 이미 만들어져 있다. 이것이 Dispatch다.

### 사용 조건

Dispatch를 사용하려면 세 가지가 필요하다.

| 조건 | 세부 사항 |
|------|-----------|
| 요금제 | Pro 또는 Max 플랜 |
| 컴퓨터 | Claude Desktop이 실행 중이어야 함 |
| 스마트폰 | Claude iOS 앱 또는 Android 앱 설치 |

컴퓨터의 Claude Desktop과 스마트폰의 Claude 앱이 같은 계정으로 로그인되어 있으면 자동으로 연결된다.

### 사용 흐름

**1단계: 스마트폰에서 지시**

출근길 지하철에서 Claude 앱을 열고 입력한다.

```
오늘 10시 회의 자료를 준비해줘.
- Google Drive '분기 실적' 폴더의 최신 데이터 사용
- PPT 10장 이내
- 첫 장에 핵심 지표 요약, 마지막 장에 다음 분기 목표
```

**2단계: 컴퓨터에서 실행**

사무실 컴퓨터의 Claude Desktop이 지시를 받아 작업을 시작한다. Google Drive에서 데이터를 가져오고, PPT를 만들고, 지정 폴더에 저장한다.

**3단계: 스마트폰에서 확인**

작업이 완료되면 스마트폰에 알림이 온다. 앱에서 결과 요약을 확인할 수 있다. 사무실에 도착하면 컴퓨터에서 완성된 파일을 열어본다.

### Dispatch에 적합한 작업

| 적합 | 부적합 |
|------|--------|
| 문서 생성 (보고서, 발표 자료) | 실시간 대화가 필요한 작업 |
| 데이터 정리 및 분석 | 민감한 데이터 접근 |
| 파일 검색 및 요약 | 여러 차례 확인이 필요한 작업 |
| 이메일 초안 작성 | 외부 시스템에 직접 전송하는 작업 |

Dispatch는 "지시 → 실행 → 확인"이라는 단방향 흐름에 최적화되어 있다. 중간에 "이거 말고 저거로 바꿔줘" 같은 수정이 필요한 작업보다는, 한 번에 명확히 지시할 수 있는 작업에 적합하다.

## 자동화 시 주의사항

자동화는 편리하지만, 아무 작업이나 자동화하면 안 된다. 다음 원칙을 지키자.

### 자동화해도 안전한 작업

- **요약 및 정리**: 이메일 요약, 뉴스 정리, 회의록 정리
- **문서 생성**: 보고서, 발표 자료, 데이터 분석 결과물
- **파일 관리**: 분류, 이름 변경, 중복 제거
- **데이터 취합**: 여러 소스의 정보를 하나로 모으기

이런 작업은 결과가 틀려도 쉽게 확인하고 수정할 수 있다.

### 자동화를 피해야 할 작업

| 위험한 자동화 | 이유 |
|--------------|------|
| 이메일/메시지 자동 발송 | 잘못된 내용이 상대방에게 전달될 수 있다 |
| 결제/구매 자동 실행 | 금전적 손실 가능성 |
| 민감한 데이터 접근 | 개인정보, 급여 정보 등의 유출 위험 |
| 시스템 설정 변경 | 되돌리기 어려운 변경이 발생할 수 있다 |
| 파일 삭제 | 중요한 파일이 영구 삭제될 수 있다 |

### 자동화 관리 습관

**정기적으로 결과를 확인한다**

자동화를 설정하고 잊어버리면 안 된다. 특히 처음 몇 주는 결과물을 꼼꼼히 확인하자. 문제가 발견되면 프롬프트를 수정하거나 스킬을 개선한다.

**작은 것부터 시작한다**

처음부터 복잡한 자동화를 만들지 말자. 단순한 작업(파일 정리, 뉴스 요약)으로 시작해서 Cowork의 자동화 결과물에 익숙해진 뒤, 점차 복잡한 워크플로우로 확장한다.

**컴퓨터 상태를 확인한다**

예약 작업은 컴퓨터가 켜져 있고 Claude Desktop이 실행 중일 때만 작동한다. 중요한 예약 작업이 있다면, 컴퓨터를 잠자기 모드로 두지 않도록 주의한다. macOS의 경우 에너지 절약 설정에서 잠자기를 비활성화할 수 있고, Windows에서는 전원 옵션에서 절전 모드를 끌 수 있다.

**예약 작업 목록을 주기적으로 정리한다**

더 이상 필요 없는 예약 작업은 삭제하거나 비활성화한다. 사이드바의 Scheduled tasks에서 전체 목록을 확인할 수 있다.

## 핵심 정리

| 기능 | 역할 | 시작 방법 |
|------|------|-----------|
| 스킬(Skills) | Cowork의 개별 능력 단위 | Customize > Skills에서 확인 |
| 커스텀 스킬 | 나만의 자동화 능력 생성 | `/skill-creator` 명령어 |
| 플러그인(Plugins) | 스킬 + 외부 연결 + 서브 에이전트 패키지 | Customize > Browse plugins |
| 예약 작업 | 정해진 시간에 자동 실행 | `/schedule` 또는 사이드바 > Scheduled tasks |
| Dispatch | 스마트폰에서 지시 → 컴퓨터에서 실행 | Claude 모바일 앱 |

자동화의 출발점은 "매번 같은 방식으로 하는 반복 작업"을 찾는 것이다. 그 작업을 Cowork에게 한 번 알려주면, 이후로는 알아서 처리된다.
