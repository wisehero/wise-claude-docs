# 실전 활용 사례

> **난이도**: 기초~중급 | **선행 문서**: [효과적인 지시 작성법](03-효과적인-지시-작성법.md) | **최초 작성**: 2026-04-13 | **마지막 수정**: 2026-04-13
>
> 직군별 실전 시나리오와 복사해서 바로 쓸 수 있는 프롬프트를 모았다. 상황에 맞는 레시피를 골라 활용하자.

---

## 이 문서 사용법

각 시나리오는 네 가지 항목으로 구성되어 있다.

| 항목 | 설명 |
|------|------|
| **상황** | 어떤 업무 상황에서 쓰는지 |
| **프롬프트** | 그대로 복사해서 사용할 수 있는 실제 지시문 |
| **예상 결과** | Cowork가 만들어주는 결과물 |
| **활용 팁** | 더 좋은 결과를 얻기 위한 조언 |

프롬프트의 `[ ]` 안 내용은 본인의 상황에 맞게 바꿔 쓴다. 예를 들어 `[회사명]`은 실제 회사 이름으로, `[파일 경로]`는 실제 폴더 위치로 교체한다.

## 마케팅

### 캠페인 성과 보고서

**상황**: 이번 달 디지털 마케팅 캠페인 성과 데이터(CSV)를 채널별로 분석해 임원 보고용 PPT를 만들어야 한다.

**프롬프트**:

```
[캠페인_성과_4월.csv]를 분석해서 마케팅 캠페인 성과 보고서를 PPT로 만들어줘.

분석: 채널별(네이버 검색광고, 카카오 모먼트, 메타, 구글 애즈) 지출·노출·클릭·전환·CPA 비교,
전월 대비 변화율(3월 데이터도 같은 폴더에 있어), ROI TOP 3, 예산 소진율

PPT 구성:
- 1장: 핵심 지표 대시보드 (총 지출, 총 전환, 평균 CPA, 전체 ROI)
- 2장: 채널별 성과 비교 차트
- 3장: 전월 대비 증감 분석
- 4장: 채널별 상세 데이터 표
- 5장: 다음 달 예산 배분 제안

금액은 '원' 단위, 천 단위 쉼표, 차트 색상은 파란색 계열로 통일.
```

**예상 결과**: 핵심 KPI 대시보드, 채널별 비교 차트, 상세 표, 예산 제안이 담긴 5장짜리 PPT.

**활용 팁**: 매월 반복한다면 스킬로 만들어 `/schedule`로 자동화할 수 있다. 지난달 PPT를 함께 첨부하면 형식 일관성이 높아진다.

---

### 소셜 미디어 콘텐츠 달력

**상황**: 블로그 아티클 5편을 기반으로 인스타그램/링크드인/X용 포스트 60개를 뽑아 콘텐츠 달력을 만들어야 한다.

**프롬프트**:

```
[블로그_폴더]의 .md 파일 5개를 읽고 소셜 미디어 콘텐츠 달력을 Excel로 만들어줘.

채널별 20개씩 총 60개:
- 인스타그램: 카드뉴스형 짧은 텍스트, 해시태그 5개
- 링크드인: 전문적 톤, 인사이트 중심, 300자 내외
- X(트위터): 캐주얼 톤, 280자 이내, 흥미 유발형

Excel 컬럼: 날짜 | 채널 | 포스트 내용 | 원본 아티클 | 이미지 제안 | 게시 시간

규칙: 하루 각 채널 1개, 같은 아티클 기반 포스트 3일 연속 금지,
게시 시간은 한국 사용자 활성 시간대(인스타 19시, 링크드인 8시, X 12시)
```

**예상 결과**: 한 달치 콘텐츠 달력 Excel. 날짜별 채널별 포스트 내용과 원본 아티클 연결 관계가 정리된다.

**활용 팁**: 브랜드 톤 가이드("친근하고 전문적, 이모지는 인스타만")를 추가하면 일관성이 높아진다.

---

### 경쟁사 분석 보고서

**상황**: 분기 전략 회의용으로 주요 경쟁사 3개사의 최근 동향 비교 보고서가 필요하다.

**프롬프트**:

```
경쟁사 분석 보고서를 Word로 만들어줘.
대상: [경쟁사A], [경쟁사B], [경쟁사C] / 우리 회사: [회사명]

분석 항목: 최근 3개월 뉴스, 신제품 출시, 마케팅 동향, 채용 공고(투자 방향 파악), 고객 리뷰 변화

구성: 기업별 섹션 + 각 섹션 끝에 "시사점" 한 문단,
마지막에 3개사 비교표(강점/약점/위협요소) + 우리 회사 대응 전략 3가지.
15페이지 이내.
```

**예상 결과**: 경쟁사별 상세 분석, 3사 비교표, 대응 방안이 담긴 Word 문서.

**활용 팁**: 웹 검색 커넥터가 연결되어 있어야 최신 뉴스를 가져올 수 있다. 이전 분기 보고서를 첨부하면 변화 추적이 가능하다.

## 재무/회계

### 월간 재무 보고서

**상황**: 영업팀, 마케팅팀, 운영팀에서 각각 보낸 비용 Excel 3개를 합쳐 월간 재무 요약 보고서를 만들어야 한다.

**프롬프트**:

```
아래 3개 Excel을 합쳐서 4월 월간 재무 보고서를 만들어줘.
파일: [영업팀_4월.xlsx], [마케팅팀_4월.xlsx], [운영팀_4월.xlsx]

시트1 - 요약: 총 매출·비용·영업이익·이익률, 부서별 비용 파이차트, 전월 대비 증감
시트2 - 부서별 상세: 항목별 비용, 예산 대비 실적([연간_예산.xlsx] 참고), 초과 항목 빨간색
시트3 - 추이: 최근 6개월 비용 추이 꺾은선 그래프

금액은 천원 단위 반올림, 비율은 소수점 1자리.
```

**예상 결과**: 요약 대시보드, 부서별 상세, 추이 분석 3개 시트로 구성된 Excel.

**활용 팁**: 각 팀 Excel 형식이 다르면 "영업팀은 A열 날짜, B열 항목, C열 금액"처럼 구조를 설명한다. 매월 반복이니 스킬로 만들어두자.

### 인보이스 처리

**상황**: 거래처에서 PDF 인보이스(청구서) 20건이 도착했다. 핵심 데이터를 추출해 하나의 Excel로 정리해야 한다.

**프롬프트**:

```
[인보이스_폴더]의 PDF 인보이스를 모두 읽고 Excel로 정리해줘.

컬럼: 파일명 | 거래처명 | 사업자번호 | 발행일 | 품목 | 수량 | 단가 | 공급가액 | 부가세 | 합계

정렬: 합계 내림차순. 마지막 행에 전체 합계.
거래처별 소계는 별도 시트. 공급가액+부가세 ≠ 합계인 건은 노란색 강조.
```

**예상 결과**: 20건의 인보이스 핵심 데이터가 하나의 Excel로 정리. 불일치 항목이 하이라이트.

**활용 팁**: 한글/영문 인보이스 혼재도 처리 가능. "ERP 입력 형식으로"라고 추가하면 시스템에 맞게 컬럼 조정.

---

### 예산 대비 실적 분석

**상황**: 1분기 종료 후 예산과 실적을 비교해 차이를 분석하고, 2분기 예산 조정 근거를 마련해야 한다.

**프롬프트**:

```
예산 대비 실적 분석을 해줘.
예산: [연간_예산.xlsx] 1분기 부분, 실적: [1분기_실적.xlsx]

분석: 항목별 예산 vs 실적 비교(차이 금액·비율, 초과=빨간/절감=파란),
부서별 소진율 그래프, 차이 TOP 5(초과/절감 각각), 2분기 예산 조정 제안.

출력: Excel(데이터) + Word(경영진 보고 요약, 3페이지)
```

**예상 결과**: 상세 분석 Excel과 경영진 보고용 Word 3페이지.

**활용 팁**: 항목 분류가 다르면 매핑을 알려준다("예산의 '광고비' = 실적의 '마케팅비'").

## 법무

### 계약서 검토

**상황**: 신규 거래처 공급 계약서 초안을 받았다. 핵심 조항을 파악하고 불리한 조건을 확인해야 한다.

**프롬프트**:

```
[공급계약서_초안.pdf]를 검토해서 Word 분석 보고서를 만들어줘.

분석: 계약 개요(당사자·기간·금액·핵심 의무),
주요 조항 요약표(조항번호 | 제목 | 핵심 내용 | 위험도 상/중/하),
불리한 조건(과도한 위약금, 일방적 해지권, 지재권 귀속, 비경쟁, 자동 갱신),
누락된 조항, 수정 제안(대안 문구 포함).

톤: 법무팀 검토 의견서 형식.
```

**예상 결과**: 위험 조항이 표시되고 수정 제안 문구가 포함된 Word 검토 의견서.

**활용 팁**: 우리 회사 표준 계약서를 함께 첨부하면 차이점 비교가 가능하다. 최종 확인은 반드시 법무 담당자에게.

---

### NDA 비교

**상황**: 파트너사 3곳의 NDA(비밀유지계약서) 조건을 비교해 가장 합리적인 안을 골라야 한다.

**프롬프트**:

```
3개 NDA를 비교해줘: [NDA_A.pdf], [NDA_B.pdf], [NDA_C.pdf]

비교표(Excel): 비밀유지 기간, 비밀정보 범위, 예외 사항, 위반 시 배상,
분쟁 해결, 준거법, 해지 조건, 반환/폐기 의무

추가 분석(Word 5페이지): NDA별 가장 불리한 조항 1개,
가장 균형 잡힌 NDA 추천(근거), 협상 시 수정 요청 포인트.
```

**예상 결과**: 한눈에 비교되는 Excel 표와 상세 분석 Word.

**활용 팁**: "비밀유지 기간 3년 이상은 불리한 것으로 표시"처럼 회사 기준을 명시하면 더 실용적.

---

### 규정 준수 체크리스트

**상황**: 개인정보보호법 개정에 따라 내부 정책과 운영 현황이 새 규정에 맞는지 점검해야 한다.

**프롬프트**:

```
규정 준수 체크리스트를 Excel로 만들어줘.
자료: [개인정보보호법_개정안.pdf], [당사_처리방침.pdf], [관리_현황.xlsx]

컬럼: 번호 | 법적 요구사항 | 정책 반영 여부 | 운영 현황 | 적합/부적합 |
조치 필요 사항 | 우선순위(상/중/하) | 담당 부서

부적합은 빨간색 배경. 마지막 시트에 개선 로드맵(1개월/3개월/6개월).
```

**예상 결과**: 요구사항별 점검표 Excel. 부적합 항목이 강조되고 개선 로드맵 포함.

**활용 팁**: 분기별 예약 작업으로 설정하면 정기 점검이 자동화된다.

## 운영/관리

### 파일 정리

**상황**: 공유 드라이브에 2년간 파일 500개 이상이 뒤섞여 있다. 프로젝트별, 연도별로 정리하고 중복을 제거해야 한다.

**프롬프트**:

```
[프로젝트_자료] 폴더를 정리해줘.

폴더 구조: 연도별 > 프로젝트별 > 기획/디자인/보고서/기타
파일명으로 프로젝트 추측, 수정일 기준 연도 배치.
동일 파일명이 여러 개면 최신만 남기고 나머지는 '중복_백업' 폴더로.

실제 이동 전에 정리 계획을 먼저 보여줘.
완료 후: 이동 내역 Excel(원래 경로 | 새 경로 | 분류 근거),
중복 파일 목록, 미분류 파일 목록.
```

**예상 결과**: 체계적 폴더 구조, 이동 내역 Excel, 중복/미분류 목록.

**활용 팁**: "정리 계획만 보여줘, 실제 이동은 하지 말고"를 먼저 요청하면 안전하다. 이후 매주 자동 정리를 예약하면 재발 방지.

---

### 회의록 정리

**상황**: 1시간 팀 회의 트랜스크립트(텍스트 변환본)에서 핵심을 정리하고 액션 아이템을 배정해야 한다.

**프롬프트**:

```
[팀회의_0410_트랜스크립트.txt]로 회의록을 Word로 만들어줘.
참석자: 김팀장, 이대리, 박사원, 최주임 / 안건: 2분기 킥오프

구성: 회의 개요, 안건별 주요 논의(발언자 구분, 합의사항 볼드),
결정 사항 목록, 액션 아이템 표(번호 | 항목 | 담당자 | 기한),
다음 회의 일정. 잡담은 제외.
```

**예상 결과**: 안건별 논의, 결정 사항, 담당자별 액션 아이템이 정리된 Word 회의록.

**활용 팁**: 정기 회의라면 이전 회의록을 첨부하고 "지난 액션 아이템 이행 여부도 확인해줘"라고 요청.

### 온보딩 자료 준비

**상황**: 신입 직원 입사를 앞두고 여러 사내 문서에서 필요한 내용만 뽑아 온보딩 가이드를 만들어야 한다.

**프롬프트**:

```
아래 문서로 신입 직원용 온보딩 가이드를 Word 20페이지 이내로 만들어줘.
자료: [취업규칙.pdf], [근태매뉴얼.docx], [시스템가이드.pdf], [보안정책.pdf], [복리후생.xlsx]

구성: 첫 주 일자별 체크리스트(표), 근무 규정 요약(Q&A 형식),
시스템 사용법, 보안 수칙 TOP 10, 복리후생 한눈에 보기(표).
톤: 신입이 부담 없이 읽을 수 있는 친근한 말투.
```

**예상 결과**: 여러 문서의 핵심만 추린 읽기 쉬운 온보딩 가이드 Word.

**활용 팁**: "마케팅팀 신입용으로"처럼 부서를 지정하면 직군별 내용이 추가된다.

---

## 리서치/분석

### 문헌 리뷰

**상황**: 프로젝트 착수 전 관련 보고서/논문 10편을 검토하고 비교표를 만들어야 한다.

**프롬프트**:

```
[리서치_자료] 폴더의 PDF 10개를 읽고 문헌 리뷰를 만들어줘.

Excel 비교표: 문서명 | 핵심 주장 | 방법론 | 주요 수치 | 적용 가능 인사이트 | 신뢰도(상/중/하)
신뢰도 기준: 발행 기관 권위, 데이터 최신성, 방법론 엄밀성

Word 종합 분석(10페이지): 공통 발견사항, 상충 주장, 연구 트렌드,
추가 조사 필요 영역, 우리 프로젝트 시사점.
```

**예상 결과**: 10편 비교 Excel과 종합 분석 Word. 이틀 걸릴 작업이 수십 분으로 줄어든다.

**활용 팁**: 영어 문서도 한국어로 분석 가능. 20편 이상이면 "제목과 초록만 읽고 상위 10편을 추려줘"로 2단계 진행.

---

### 시장 조사

**상황**: 신사업 진출 검토를 위해 여러 소스의 시장 데이터를 취합하고 인사이트를 도출해야 한다.

**프롬프트**:

```
[시장분석_자료] 폴더의 파일들로 시장 조사 보고서를 만들어줘.
(통계청 데이터, 업계 리포트, 경쟁사 IR자료, 소비자 설문 등)

Word(15페이지): 시장 개요(규모·성장률·트렌드), 세분화, 경쟁 환경,
소비자 분석, SWOT, 기회와 위험, 권장 전략 3가지(근거 포함)

Excel 부록: 시장 규모 추이+차트, 경쟁사 비교표, 설문 크로스탭, 출처 목록
```

**예상 결과**: 경영진 보고용 Word 보고서와 근거 데이터 Excel.

**활용 팁**: "연매출 500억, 100억 규모로 진출 검토 중"처럼 맥락을 추가하면 현실적 분석이 나온다.

---

### 데이터 클리닝

**상황**: 고객 DB를 Excel로 내보냈는데 중복, 불완전 주소, 전화번호 형식 불일치 등 문제가 많다.

**프롬프트**:

```
[고객DB.xlsx] 데이터를 정리해줘.

규칙:
- 중복 제거: 이름+전화번호 동일 → 정보 많은 행 남김
- 전화번호: 010-XXXX-XXXX 형식 통일 (지역번호는 유지)
- 주소: '서울특별시'→'서울' 등 약칭 통일, 빈 값은 "미입력"
- 이메일: @ 없으면 "오류", 빈 값은 "미입력"
- 날짜: YYYY-MM-DD 통일

시트1: 정리된 데이터 / 시트2: 변경 로그 / 시트3: 오류 목록 / 시트4: 정리 통계
원본은 건드리지 말고 새 파일로 저장.
```

**예상 결과**: 깨끗한 데이터 Excel. 변경 이력과 오류 목록이 별도 시트에 있어 투명한 확인 가능.

**활용 팁**: 대용량이면 "처음 100행만 먼저 보여줘"로 확인 후 전체 처리.

---

## HR/인사

### 이력서 스크리닝

**상황**: 경력직 채용에 이력서 30건이 접수됐다. JD 기준으로 핵심 역량을 추출해 비교표를 만들어야 한다.

**프롬프트**:

```
아래 JD 기준으로 [이력서_폴더]의 이력서를 분석해줘.

JD: 디지털 마케팅 매니저
필수: 퍼포먼스 마케팅 3년+, 데이터 분석, 광고 플랫폼 운영
우대: SQL, GA4, B2B 마케팅

Excel 시트1 - 요약: 순위 | 이름 | 총 경력 | 필수 충족(3개 중) | 우대 충족(3개 중) | 적합도 점수 | 한줄 평가
시트2 - 상세: 역량별 상세 평가
시트3 - TOP 10: 경력 요약, 강점, 약점, 면접 확인 포인트

적합도: 필수 각 30점(90) + 우대 각 10점(30) = 120점 만점, 내림차순 정렬.
```

**예상 결과**: 30명이 적합도 순 정렬된 Excel. 상위 10명의 상세 분석과 면접 포인트 포함.

**활용 팁**: 공정 채용을 위해 "나이, 성별, 출신 학교는 분석에서 제외해줘"라고 명시할 수 있다.

---

### 직원 설문 분석

**상황**: 반기별 직원 만족도 설문 200명 응답을 분석해 트렌드와 개선 방안을 도출해야 한다.

**프롬프트**:

```
[직원만족도_설문.xlsx]를 분석해줘.
(5점 척도 20문항 + 주관식 3문항, 부서·직급·근속연수 포함)

분석: 전체·영역별 만족도, 부서별·직급별·근속연수별 비교(차트),
주관식 키워드 분석(긍정/부정 TOP 10), 전기 대비 변화(전기 파일 있으면),
시급한 개선 TOP 3 + 유지 강화 TOP 3 + 구체적 실행 방안.

출력: Excel(상세 데이터+차트) + PPT(경영진 보고용, 10장 핵심만)
```

**예상 결과**: 데이터 분석 Excel과 경영진 보고용 PPT. 실행 가능한 개선 제안 포함.

**활용 팁**: "부서별 액션 플랜도 각각 만들어줘"라고 하면 더 세분화된 결과를 받을 수 있다.

---

### 교육 자료 제작

**상황**: 사내 정보보안 교육 자료를 만들어야 한다. 보안 규정에서 핵심을 추출해 교육용 PPT와 퀴즈를 만든다.

**프롬프트**:

```
[보안_규정.pdf]와 [보안사고_사례집.pdf]로 정보보안 교육 자료를 만들어줘.

PPT(20장): 보안의 중요성(사고 사례 기반), 일상 보안 수칙(비밀번호·피싱·USB·원격근무·개인정보),
사고 대응 절차, 자주 하는 실수 TOP 5, 요약

Word 퀴즈: 객관식 15문제(쉬움5·보통7·어려움3) + 정답·해설.
실제 업무 시나리오로 출제.

Word 1페이지 요약본: 책상에 붙이는 보안 수칙 체크리스트(A4, 큰 글씨).

톤: 딱딱한 규정이 아닌, 이해하기 쉬운 일상 언어로.
```

**예상 결과**: 교육 PPT, 퀴즈, 1페이지 요약본 세 가지. 규정의 딱딱한 내용이 읽기 쉽게 변환.

**활용 팁**: "개발팀용에는 소스코드 관리 문제를 추가"처럼 부서별 커스터마이징 가능.

## 시나리오 활용 팁 종합

### 좋은 프롬프트의 공통 패턴

| 요소 | 나쁜 예 | 좋은 예 |
|------|---------|---------|
| 입력 지정 | "파일을 분석해줘" | "[매출_데이터.xlsx]를 분석해줘" |
| 출력 형식 | "보고서를 만들어줘" | "Excel 3개 시트 + Word 5페이지" |
| 구조 지정 | "정리해줘" | "표로 정리. 컬럼은 이름, 금액, 비율" |
| 기준 명시 | "중요한 것만" | "금액 100만원 이상인 항목만" |
| 예외 처리 | (언급 없음) | "빈 셀은 'N/A'로 표시" |

### 결과물 품질을 높이는 3가지 습관

**1. 예시를 보여준다**: 지난달 보고서를 첨부하면 형식과 톤을 맞춘다.

**2. 단계를 나눈다**: "먼저 데이터 구조를 파악해줘" → 확인 → "이제 분석해줘" → 확인 → "PPT로 만들어줘"

**3. 피드백을 구체적으로 한다**: "다시 해줘" 대신 "3페이지 차트 X축 레이블이 잘려. 글씨를 줄이고 범례는 아래로 옮겨줘"

## 핵심 정리

| 직군 | 대표 활용 사례 | 핵심 도구 |
|------|----------------|-----------|
| 마케팅 | 캠페인 분석, 콘텐츠 달력, 경쟁사 분석 | CSV 분석, PPT, 웹 검색 |
| 재무/회계 | 재무 보고, 인보이스 처리, 예산 분석 | Excel 합산, PDF 추출 |
| 법무 | 계약서 검토, NDA 비교, 규정 준수 | PDF 분석, 비교표 |
| 운영/관리 | 파일 정리, 회의록, 온보딩 자료 | 파일 관리, 트랜스크립트 |
| 리서치/분석 | 문헌 리뷰, 시장 조사, 데이터 클리닝 | 다중 PDF, 데이터 정리 |
| HR/인사 | 이력서 스크리닝, 설문 분석, 교육 자료 | PDF/Word 분석, 퀴즈 |

어떤 직군이든 핵심은 같다. **구체적인 입력, 명확한 출력 형식, 판단 기준**을 프롬프트에 담으면 원하는 결과를 얻을 수 있다.
