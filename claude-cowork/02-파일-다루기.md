## 폴더 공유의 원리

Cowork가 내 컴퓨터의 파일에 접근하려면, 먼저 **폴더를 공유**해야 한다. 공유하지 않은 폴더는 Cowork가 볼 수 없다.

### 비유: 공유 드라이브

회사에서 새로 온 동료에게 업무를 맡길 때, 모든 서류함을 열어주지는 않는다. "이 프로젝트 관련 자료는 여기에 있어요"라며 특정 폴더만 알려주는 것과 같다. Cowork도 마찬가지다.

### 접근 가능 / 불가능한 영역

| 접근 가능 | 접근 불가 |
|-----------|-----------|
| 사용자가 직접 공유한 폴더 | 바탕화면 전체 (Desktop) |
| 공유 폴더 안의 모든 하위 폴더 | 문서 폴더 전체 (Documents) |
| 공유 폴더 안의 모든 파일 | 시스템 폴더 (Applications, Library 등) |
| | 다른 앱의 데이터 |

공유 폴더를 설정하는 방법은 간단하다.

1. Cowork 대화 화면에서 폴더 공유 버튼을 누른다
2. 원하는 폴더를 선택한다
3. 또는 Finder(macOS)나 탐색기(Windows)에서 폴더를 Cowork 창으로 끌어다 놓는다

한 번 공유하면 해당 세션 동안 그 폴더 안의 파일을 자유롭게 읽고 쓸 수 있다.

## 전용 작업 폴더 만들기

Cowork를 쓸 때 가장 중요한 습관은 **전용 작업 폴더를 따로 만드는 것**이다.

### 나쁜 방식 → 좋은 방식

**나쁜 방식**: ~/Documents/ 전체를 공유한다. 개인 파일과 업무 파일이 구분 없이 노출되고, 탐색 범위도 불필요하게 넓어진다.

**좋은 방식**: 전용 작업 폴더를 만들어 필요한 파일만 넣는다.

```
~/Cowork-작업/
├── 4월-매출분석/
│   ├── 매출데이터.xlsx
│   └── 지난달-보고서.pdf
├── 마케팅-캠페인/
│   └── 광고비용.csv
└── 파일정리-요청/
    └── (정리할 파일들)
```

### 이렇게 해보세요

바탕화면이나 홈 디렉토리에 아래 폴더를 만들어두자.

```
~/Cowork-작업/
```

작업이 생길 때마다 이 안에 프로젝트별 하위 폴더를 만들고, 필요한 파일을 복사해 넣는다. 원본 파일은 원래 위치에 그대로 두고, **복사본으로 작업하는 것**이 안전하다. Cowork가 파일을 수정하더라도 원본에는 영향이 없기 때문이다.

## 파일 읽기와 분석

Cowork는 다양한 형식의 파일을 읽고 내용을 이해할 수 있다.

### 읽을 수 있는 파일 형식

| 형식 | 확장자 | 활용 예시 |
|------|--------|-----------|
| PDF 문서 | .pdf | 계약서 분석, 보고서 요약 |
| 스프레드시트 | .xlsx, .csv | 매출 분석, 데이터 정리 |
| 워드 문서 | .docx | 문서 수정, 요약 |
| 이미지 | .png, .jpg | 이미지 속 텍스트 인식, 내용 설명 |
| 텍스트 | .txt, .md | 내용 분석, 형식 변환 |
| 프레젠테이션 | .pptx | 슬라이드 내용 분석 |

파일 하나의 최대 크기는 **30MB**다. 그보다 큰 파일은 분할하거나 필요한 부분만 추출해서 공유해야 한다.

### 실전 예시: 계약서 분석

**나쁜 지시**

```
이 계약서 봐줘.
```

"봐줘"가 무슨 뜻인지 Claude는 추측해야 한다. 요약인가? 문제점 찾기인가? 특정 조항 확인인가?

**좋은 지시**

```
이 계약서 PDF를 읽고 아래 항목을 정리해줘.

1. 계약 기간 (시작일, 종료일, 자동갱신 여부)
2. 위약금 조건 (중도 해지 시 금액 또는 비율)
3. 지적재산권 귀속 (누구에게 귀속되는지)
4. 비밀유지 의무 기간

결과는 표 형식으로 정리하고, 특이사항이 있으면 별도로 알려줘.
```

### 실전 예시: 스프레드시트 분석

```
이 Excel은 2025년 월별 매출 데이터야.
분석해줘: 월별 추이(상승/하락 표시), 전월 대비 증감률, 최고/최저 달, 상반기 vs 하반기 비교
결과를 새 Excel 파일로 만들어줘. 차트도 포함해줘.
```

### 여러 파일을 한 번에 분석하기

Cowork의 강점 중 하나는 여러 파일을 동시에 읽고 비교할 수 있다는 점이다.

```
이 폴더에 있는 세 개의 견적서(A사.pdf, B사.pdf, C사.pdf)를 비교해줘.

비교 항목: 총 금액, 납품 기간, 보증 조건, 유지보수 비용
결과는 비교표로 만들어줘.
```

파일을 하나씩 업로드하며 대화할 필요 없이, 폴더에 넣어두고 한 번에 처리할 수 있다.

## 파일 생성하기

Cowork는 대화만으로 다양한 형식의 파일을 만들어준다.

### 생성 가능한 파일 형식

| 형식 | 확장자 | 특징 |
|------|--------|------|
| Excel | .xlsx | 수식, 차트, 서식 포함 가능 |
| Word | .docx | 제목, 본문, 표 등 서식 적용 가능 |
| PowerPoint | .pptx | 슬라이드 레이아웃, 텍스트 배치 |
| PDF | .pdf | 완성된 문서를 PDF로 출력 |
| CSV | .csv | 단순 데이터 파일 |

### 형식별 프롬프트 예시

**Excel 만들기**

```
첨부한 CSV 매출 데이터를 기반으로 Excel 보고서를 만들어줘.
시트 1: 원본 데이터(서식 정리, 헤더 굵게, 천 단위 쉼표)
시트 2: 월별 합계 피벗 테이블 / 시트 3: 매출 추이 꺾은선 차트
파일 이름: 2026-04-13_매출분석.xlsx
```

**Word 만들기**

```
아래 내용으로 회의록을 Word 파일로 만들어줘.
회의 일시: 2026-04-13 14:00 / 참석자: 김영희, 이철수, 박지민
안건: 2분기 마케팅 예산 확정
논의: 디지털 광고 30% 증액 합의, SNS 배분은 다음 주까지 제안, 오프라인은 동결
형식: 회사 회의록 양식(날짜, 참석자, 안건, 논의, 결정사항, 후속 조치)
파일 이름: 2026-04-13_마케팅팀_회의록.docx
```

**PowerPoint 만들기**

```
매출분석.xlsx를 기반으로 경영진 보고용 PPT를 만들어줘.
구성: 표지 → 핵심 수치 3개 → 월별 추이 차트 → 부서별 비교 → 시사점(3~5개)
디자인: 깔끔하고 전문적, 파란색 계열 / 파일 이름: 2025_연간매출분석_발표자료.pptx
```

### 하나의 프롬프트로 여러 파일 만들기

```
첨부한 CSV 매출 데이터로 아래 세 파일을 만들어줘.
1. 분석 Excel: 피벗+차트 (매출분석_상세.xlsx)
2. 요약 Word: A4 한 장 (매출분석_요약.docx)
3. 발표 PPT: 경영진용 5장 (매출분석_발표.pptx)
세 파일의 수치와 결론이 서로 일치하도록 해줘.
```

CSV 하나에서 분석, 요약, 발표 자료까지 한 번에 나온다. 이것이 Cowork의 진정한 강점이다.

## 파일 정리와 분류

파일이 쌓이면 정리에 막대한 시간이 든다. Cowork는 수백 개의 파일도 몇 분 안에 분류할 수 있다.

### 실전 사례: 600개 파일 정리

어지럽게 쌓인 600개 이상의 파일을 종류와 날짜별로 정리하는 데 약 2분이 걸린다. 사람이 하면 반나절 이상 걸릴 작업이다.

### 파일 이름 일괄 변경

**나쁜 지시**: "파일 이름 바꿔줘" -- 어떤 규칙으로 바꿀지 알 수 없다.

**좋은 지시**:

```
이 폴더의 사진 파일 이름을 [촬영날짜]_[순번].확장자 형식으로 바꿔줘.
예: 2026-04-13_001.jpg / 날짜 모르면 "날짜미상_001.jpg"
변경 전후 대조표를 CSV로 만들어줘.
```

### 폴더별 분류

```
이 폴더의 파일들을 종류별 하위 폴더로 분류해줘.
문서(.pdf/.docx/.xlsx) → "문서", 이미지(.jpg/.png) → "이미지", 압축(.zip) → "압축파일", 나머지 → "기타"
각 폴더에 몇 개 파일이 들어갔는지 요약도 보여줘.
```

### 중복 파일 찾기

```
이 폴더에서 내용이 같은 중복 파일을 찾아줘.
파일 이름이 달라도 내용이 같으면 중복으로 간주해줘.
삭제하지 말고 목록만 보여주고, 어떤 걸 남길지 제안해줘.
```

### 파일 목록(매니페스트) 만들기

```
이 폴더의 전체 파일 목록을 Excel로 만들어줘.
포함할 정보: 파일 이름, 확장자, 파일 크기, 수정 날짜, 위치(하위 폴더 경로)
파일 이름: 파일목록_2026-04-13.xlsx
```

## Google Drive 연동

Cowork는 Google Drive와 연결하여 클라우드 파일을 다루거나, 결과물을 Drive에 바로 저장할 수 있다.

### 연동 설정

1. Claude Desktop 설정에서 **Connectors** (커넥터) 항목을 연다
2. Google Drive를 선택하고 Google 계정으로 로그인한다
3. 접근 권한을 허용하면 연동 완료

### 활용 예시

```
# Drive에서 파일 읽기
내 Google Drive의 "2025년 실적" 폴더에서 "분기별매출.xlsx"를 읽고 하반기 추이를 분석해줘.

# 결과를 Drive에 저장
이 분석 보고서를 내 Google Drive의 "보고서" 폴더에 저장해줘.

# 팀 공유 폴더에 저장
완성된 프레젠테이션을 Google Drive 공유 폴더 "마케팅팀/2026-2Q"에 저장해줘.
```

팀원들과 파일을 공유해야 할 때 특히 유용하다. Cowork가 만든 결과물을 매번 수동으로 Drive에 올리지 않아도 된다.

## 주의할 점

Cowork는 강력하지만, 파일을 다룰 때 몇 가지 주의사항이 있다.

### 파일 삭제는 신중하게

Cowork는 파일을 삭제할 수 있지만, 기본적으로 삭제 전에 사용자에게 확인을 요청한다. 그래도 안전을 위해 다음 원칙을 지키자.

- 정리 작업 시 "삭제하지 말고 목록만 보여줘"로 먼저 확인한다
- 중요한 파일은 작업 전에 반드시 백업해둔다
- 삭제가 필요하면 "이 5개 파일을 삭제해줘"처럼 구체적으로 지시한다

### 백업 습관

| 상황 | 권장 행동 |
|------|-----------|
| 첫 사용 시 | 연습용 폴더에서 복사본으로 연습 |
| 중요한 파일 작업 | 원본을 별도 위치에 복사해두고 시작 |
| 대량 파일 정리 | 정리 전에 폴더 전체를 통째로 복사 |
| 이름 일괄 변경 | 변경 전 목록을 CSV로 먼저 뽑아두기 |

### 민감한 데이터 주의

Cowork와의 대화 내용은 Anthropic 서버를 거쳐 처리된다. 다음과 같은 파일은 공유 폴더에 넣지 않는 것이 좋다.

- 비밀번호가 적힌 파일
- 개인정보(주민등록번호, 카드번호 등)가 포함된 파일
- 회사 기밀 등급이 높은 문서
- 인증서 파일, API 키 파일

확실하지 않다면 회사의 보안 정책을 먼저 확인하자.

### 대용량 파일 처리

- 파일 하나의 크기가 **30MB**를 넘으면 처리가 안 될 수 있다
- 수천 행이 넘는 대형 스프레드시트는 처리 시간이 길어진다
- 대용량 파일은 필요한 시트나 범위만 추출해서 공유하는 것이 효율적이다

### 파일 형식 관련 팁

| 상황 | 팁 |
|------|-----|
| 스캔 PDF (이미지 PDF) | 텍스트 인식(OCR)이 가능하지만, 정확도가 떨어질 수 있다 |
| 암호 걸린 파일 | 암호가 걸린 Excel/PDF는 읽을 수 없다. 암호를 먼저 해제해야 한다 |
| 한글(.hwp) | 한글 파일은 직접 읽을 수 없다. PDF나 DOCX로 변환 후 사용한다 |
| 동영상/음성 | 영상(.mp4)이나 음성(.mp3) 파일은 지원하지 않는다 |

## 실전 활용 시나리오: 월말 보고서 만들기

매월 반복되는 보고서 작성을 Cowork로 처리하는 흐름이다.

**1단계**: 작업 폴더에 데이터를 모은다 (매출_원본.xlsx, 비용_원본.xlsx, 지난달_보고서.docx).

**2단계**: 한 번에 분석과 산출물 생성을 요청한다.

```
이 폴더에 매출과 비용 데이터가 있어.

1. 두 파일을 읽고 4월 영업이익(매출-비용)을 계산해줘
2. 전월 대비 증감을 분석해줘
3. 부서별 비교 차트를 만들어줘

결과물: 분석 Excel(4월_실적분석.xlsx), 요약 Word(4월_월간보고서.docx — 지난달 형식 참고), 경영진 PPT 3장(4월_경영보고.pptx)
```

**3단계**: 결과를 확인하고, 필요하면 추가 지시한다 ("차트 제목 바꿔줘", "슬라이드 추가해줘" 등).

반복 작업은 프롬프트를 메모장에 저장해두고 매월 데이터만 바꿔서 재사용하면 더 효율적이다.

## 핵심 정리

- Cowork는 사용자가 직접 공유한 폴더만 접근할 수 있다. 컴퓨터 전체에 접근하는 것이 아니다.
- 전용 작업 폴더(`~/Cowork-작업/`)를 만들어 원본 대신 복사본으로 작업하는 습관을 들이자.
- PDF, Excel, Word, 이미지 등 다양한 형식의 파일을 읽고 분석할 수 있으며, 파일 하나당 최대 30MB까지 처리한다.
- Excel, Word, PowerPoint, PDF 파일을 생성할 수 있고, 하나의 프롬프트로 여러 파일을 동시에 만들 수 있다.
- 파일 정리(분류, 이름 변경, 중복 찾기)는 Cowork가 가장 빛나는 작업 중 하나다.
- 민감한 데이터가 담긴 파일은 공유 폴더에 넣지 않도록 주의한다.
- 나쁜 지시("봐줘", "정리해줘")보다 구체적인 지시(항목, 형식, 파일 이름 지정)가 훨씬 나은 결과를 가져온다.
