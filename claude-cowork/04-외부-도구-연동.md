>
> Cowork에 외부 서비스를 연결하여 이메일, 캘린더, 문서 협업, 화상회의 등 업무 범위를 확장하는 방법을 다룬다.

## 커넥터란?

Cowork은 기본적으로 로컬 파일을 다루는 데 강하다. 하지만 실무에서는 Gmail, Google Drive, 캘린더 같은 외부 서비스와 연동해야 할 때가 많다. 이때 사용하는 것이 **커넥터**(Connector)다.

커넥터는 Cowork과 외부 서비스 사이의 **다리** 역할을 한다. 기술적으로는 MCP(Model Context Protocol)라는 표준 프로토콜을 사용하지만, 사용자가 이 기술을 이해할 필요는 없다. 그냥 "Cowork이 Gmail에 접근할 수 있게 해주는 연결 장치" 정도로 생각하면 된다.

### 커넥터 연결 방법

1. Cowork 설정(Settings) 메뉴를 연다
2. **Connectors** 탭을 선택한다
3. 연결할 서비스(예: Gmail)의 **Connect** 버튼을 클릭한다
4. OAuth 인증(일회성 로그인 — 해당 서비스에서 "Cowork에 접근을 허용하시겠습니까?"라고 묻는 화면)을 완료한다

인증은 최초 한 번만 하면 된다. 이후에는 별도의 로그인 없이 Cowork이 해당 서비스에 접근할 수 있다.

### 커넥터의 권한 범위

커넥터는 **최소 권한 원칙**을 따른다. 예를 들어 Gmail 커넥터는 이메일을 읽고, 검색하고, 초안을 만들 수 있지만, 이메일을 직접 발송하지는 않는다. 발송은 반드시 사용자가 직접 확인하고 보내야 한다. 이는 실수로 잘못된 이메일이 전송되는 것을 방지하기 위한 안전장치다.

## 이메일 업무 — Gmail 연동

이메일은 직장인이 가장 많은 시간을 쓰는 업무 중 하나다. Gmail 커넥터를 연결하면 Cowork이 이메일을 검색하고, 분류하고, 답변 초안을 만들어줄 수 있다.

### 사용 가능한 기능

| 기능 | 설명 | 직접 실행 여부 |
|------|------|----------------|
| 이메일 검색 | 조건별 이메일 찾기 (발신자, 키워드, 날짜 등) | Cowork이 직접 검색 |
| 이메일 읽기 | 이메일 본문 확인 | Cowork이 직접 읽기 |
| 초안 작성 | 답변 또는 새 이메일 초안 생성 | Cowork이 초안 생성 |
| 이메일 발송 | 실제 전송 | **사용자가 직접 확인 후 전송** |
| 라벨 관리 | 이메일에 라벨(태그) 추가/제거 | Cowork이 직접 실행 |

> **중요**: Cowork은 이메일 초안을 만들지, 직접 보내지 않는다. 초안을 확인하고 발송 버튼을 누르는 것은 항상 사용자의 몫이다.

### 실전 시나리오: 고객 문의 일괄 처리

**상황**: 지난주에 들어온 고객 문의 이메일이 쌓여 있다. 주제별로 분류하고 각각에 대한 답변 초안이 필요하다.

```
지난주(4월 6일~12일) 받은 이메일 중 제목이나 본문에 "문의", "질문", "요청"이 
포함된 이메일을 찾아줘.

찾은 이메일을 아래 기준으로 분류해줘:
- 제품 문의
- 배송/교환
- 결제/환불
- 기타

각 이메일에 대해 답변 초안을 만들어줘.
- 톤: 정중한 비즈니스 격식체
- 분량: 5~10줄
- 공통 멘트: "추가 문의 사항은 고객센터(1588-XXXX)로 연락 주세요"를 마지막에 넣어줘

결과를 표로 정리해줘:
| 발신자 | 제목 | 분류 | 초안 요약(한 줄) |
```

Cowork은 Gmail에서 조건에 맞는 이메일을 검색하고, 내용을 읽어 분류한 뒤, 각각에 대한 답변 초안을 생성한다. 사용자는 초안을 검토하고 필요하면 수정한 뒤 발송한다.

### 활용 팁

- **정기 업무**: 매주 같은 형식으로 이메일을 분류해야 한다면, 위 지시를 저장해두고 날짜만 바꿔서 반복 사용한다
- **답변 톤 통일**: 팀에서 사용하는 이메일 양식이 있다면 예시로 포함하면 일관된 톤의 답변이 나온다
- **라벨 정리**: "이 이메일들에 '처리완료' 라벨을 붙여줘"로 후속 정리도 가능하다

## 문서 협업 — Google Drive 연동

Google Drive 커넥터를 연결하면 Cowork이 Drive에 저장된 문서를 읽고, 새 문서를 만들어 저장할 수 있다. 여러 문서에 흩어진 정보를 하나로 모으는 데 특히 효과적이다.

### 사용 가능한 기능

| 기능 | 설명 |
|------|------|
| 문서 검색 | 파일명, 폴더, 키워드로 Drive 내 문서 찾기 |
| 문서 읽기 | Google Docs, Sheets, Slides의 내용 읽기 |
| URL로 접근 | 문서의 공유 링크를 제공하면 직접 접근 |
| 문서 저장 | 새 문서를 생성하거나 기존 문서를 업데이트하여 Drive에 저장 |

### 실전 시나리오: 분기 보고서 통합 요약

**상황**: Google Drive의 특정 폴더에 각 팀이 올린 분기 보고서가 5개 있다. 이것들을 읽고 하나의 요약 문서로 통합해야 한다.

```
Google Drive의 "2026 Q1 보고서" 폴더에 있는 모든 문서를 읽어줘.

각 문서에서 다음을 추출해줘:
- 팀명
- 분기 핵심 성과 (3개 이내)
- 주요 수치 (매출, 비용, KPI 달성율)
- 다음 분기 계획 요약

추출한 내용을 하나의 통합 요약 문서로 만들어줘.
- 형식: Google Docs
- 구성: 전체 요약(1페이지) → 팀별 상세(각 반 페이지)
- 저장 위치: 같은 "2026 Q1 보고서" 폴더
- 파일명: "Q1 통합 요약 보고서"
```

### Enterprise 기능: 문서 인덱싱

기업용(Enterprise) 플랜에서는 **RAG 기반 Google Docs 인덱싱**(RAG — Retrieval-Augmented Generation, 검색 증강 생성. 저장된 문서를 미리 색인화해서 필요할 때 빠르게 찾아 활용하는 기술)을 사용할 수 있다. 이 기능을 활성화하면 Cowork이 Drive 전체 문서를 미리 색인화하여, "지난달 마케팅 예산 관련 문서가 뭐가 있었지?"라고 물으면 관련 문서를 즉시 찾아준다.

## 일정 관리 — Google Calendar 연동

Google Calendar 커넥터를 연결하면 Cowork이 일정을 확인하고, 새 일정을 만들거나, 빈 시간을 찾아줄 수 있다.

### 사용 가능한 기능

| 기능 | 설명 |
|------|------|
| 일정 조회 | 특정 기간의 일정 확인 |
| 일정 생성 | 새 일정 추가 (제목, 시간, 참석자, 설명 포함) |
| 일정 수정 | 기존 일정의 시간, 제목 등 변경 |
| 일정 삭제 | 일정 제거 |
| 빈 시간 확인 | 특정 기간에 비어 있는 시간대 검색 |

### 실전 시나리오: 빈 시간에 업무 블록 잡기

**상황**: 다음 주 중에 분기 리뷰를 준비할 2시간짜리 집중 시간이 필요하다. 기존 일정과 겹치지 않는 시간을 찾아야 한다.

```
다음 주 월요일(4월 20일)부터 금요일(4월 24일)까지의 일정을 확인해줘.

비어 있는 시간 중 2시간 연속 블록이 가능한 시간대를 모두 알려줘.
- 업무 시간: 09:00 ~ 18:00
- 점심시간(12:00~13:00)은 제외

그 중 가장 이른 시간에 아래 일정을 잡아줘:
- 제목: 분기 리뷰 준비
- 설명: Q1 성과 자료 정리 및 발표 준비
- 알림: 30분 전
```

### 활용 팁

- **일정 충돌 확인**: "이번 주에 겹치는 일정이 있는지 확인해줘"
- **반복 일정**: "매주 금요일 오후 3시에 '주간 회고' 30분짜리 일정을 만들어줘"
- **일정 요약**: "이번 주 일정을 요일별로 정리해줘. 빈 시간도 같이 알려줘"

## 회의 관리 — Zoom 연동

Zoom 커넥터를 연결하면 회의 녹화본에서 내용을 추출하고, 회의록을 자동으로 생성할 수 있다. 회의 후 후속 작업(액션 아이템 정리, 회의록 배포)에 특히 유용하다.

### 사용 가능한 기능

| 기능 | 설명 |
|------|------|
| 회의 요약 | 녹화된 회의의 핵심 내용 요약 |
| 액션 아이템 추출 | 회의에서 나온 할 일 목록 정리 |
| 녹취록 접근 | 회의 전체 녹취록(transcript) 확인 |
| 참석자 확인 | 회의 참석자 목록 조회 |

### 실전 시나리오: 회의 후 액션 아이템 정리

**상황**: 오늘 오전에 1시간짜리 팀 회의를 Zoom으로 진행했다. 회의에서 나온 할 일들을 담당자별로 정리해서 팀에 공유해야 한다.

```
오늘 오전 팀 회의(10:00~11:00) 녹화본에서 다음을 추출해줘:

1. 회의 요약 (5줄 이내)
2. 주요 논의 사항 (안건별 2-3줄)
3. 결정 사항 (확정된 내용만)
4. 액션 아이템을 담당자별로 정리:

| 담당자 | 할 일 | 마감일 | 우선순위(상/중/하) |
|--------|--------|--------|--------------------|

결과를 Excel(meeting_action_items_0413.xlsx)로 저장해줘.
```

### 활용 팁

- **회의록 양식 통일**: 매번 같은 형식의 회의록 템플릿을 사용하면 팀 전체가 일관된 형식으로 기록을 관리할 수 있다
- **후속 이메일**: 회의록을 정리한 뒤 "이 내용을 참석자들에게 보낼 이메일 초안으로 만들어줘"로 바로 연결 가능하다
- **시리즈 관리**: "지난 4주간의 팀 회의 액션 아이템 중 아직 완료되지 않은 것을 정리해줘"로 누적 관리도 가능하다

## 계약 관리 — DocuSign 연동

DocuSign 커넥터는 계약서와 서명 워크플로를 Cowork에서 다룰 수 있게 해준다. 계약서 내용 분석, 핵심 조항 추출, 서명 요청 현황 관리에 활용된다.

### 사용 가능한 기능

| 기능 | 설명 |
|------|------|
| 계약서 읽기 | 업로드된 계약서 내용 확인 |
| 조항 분석 | 핵심 조항 추출 및 요약 |
| 서명 상태 확인 | 서명 요청의 진행 상황 조회 |
| 워크플로 관리 | 서명 순서, 마감일 관리 |

### 실전 시나리오: 계약서 검토

**상황**: 파트너사에서 보내온 협업 계약서를 검토해야 한다. 핵심 조항을 빠르게 파악하고, 우리 측에 불리한 조건이 있는지 확인하고 싶다.

```
DocuSign에서 "2026 파트너십 계약서"를 읽어줘.

다음을 정리해줘:
1. 계약 기본 정보 (당사자, 계약 기간, 금액)
2. 핵심 조항 요약 (10개 이내, 각 2줄)
3. 아래 관점에서 리스크 분석:
   - 자동 갱신 조항이 있는가?
   - 해지 조건과 위약금은?
   - 지식재산권 귀속은 어떻게 되는가?
   - 우리 측에 불리한 일방적 조건이 있는가?
4. 주의가 필요한 조항은 별도로 표시하고 이유를 설명해줘

결과를 표로 정리해줘:
| 조항 | 요약 | 리스크 수준(상/중/하) | 비고 |
```

> **주의**: Cowork의 분석은 법률 자문을 대체하지 않는다. 중요한 계약은 반드시 법무팀이나 법률 전문가의 검토를 받아야 한다. Cowork은 핵심 조항을 빠르게 파악하고 검토 포인트를 정리하는 데 활용한다.

## 금융 데이터 — FactSet/MSCI 연동

금융권이나 투자 관련 업무를 한다면 FactSet, MSCI 커넥터를 통해 시장 데이터, 기업 재무정보, 인덱스 데이터에 접근할 수 있다.

### 사용 가능한 기능

| 커넥터 | 주요 기능 |
|--------|-----------|
| FactSet | 기업 재무제표, 실적 추정치, 시장 데이터, 산업 분석 |
| MSCI | 인덱스 데이터, ESG(환경·사회·지배구조) 평가, 리스크 분석 |

### 실전 시나리오: 경쟁사 실적 비교

**상황**: 반도체 산업 리서치를 위해 삼성전자와 SK하이닉스의 최근 분기 실적을 비교해야 한다.

```
FactSet에서 삼성전자(005930.KS)와 SK하이닉스(000660.KS)의 
최근 분기(2026 Q1) 실적을 가져와줘.

비교 항목:
- 매출
- 영업이익
- 영업이익률
- 순이익
- 전분기 대비 증감율
- 컨센서스(시장 추정치) 대비 서프라이즈 여부

결과를 비교표로 정리해줘:
| 항목 | 삼성전자 | SK하이닉스 | 비고 |
|------|----------|------------|------|

마지막에 한 줄 요약을 추가해줘.
```

### 활용 팁

- **정기 모니터링**: "매주 월요일에 반도체 대형주 5개의 주간 수익률을 비교표로 만들어줘"
- **산업 분석**: "2025년 글로벌 반도체 시장 매출 상위 10개사를 정리해줘"
- **ESG 분석**: "MSCI ESG 등급 기준으로 국내 주요 기업 10개를 정리해줘"

## 기타 커넥터

Cowork은 위에서 다룬 서비스 외에도 다양한 외부 도구와 연결할 수 있다. 아래는 현재 사용 가능한 주요 커넥터 목록이다.

| 커넥터 | 용도 | 주요 기능 |
|--------|------|-----------|
| Apollo | 영업 인텔리전스 | 잠재 고객 검색, 연락처 정보, 기업 데이터 |
| Clay | 데이터 강화 | 고객/리드 정보 자동 수집 및 강화 |
| Outreach | 영업 자동화 | 이메일 시퀀스, 영업 활동 관리, 성과 분석 |
| Similarweb | 웹 분석 | 웹사이트 트래픽 분석, 경쟁사 벤치마킹 |
| LegalZoom | 법률 서비스 | 법인 설립, 상표 등록, 법률 문서 작성 |
| WordPress | 콘텐츠 관리 | 블로그 포스트 작성, 페이지 관리 |
| Harvey | 법률 AI | 법률 문서 분석, 계약서 검토, 법률 리서치 |
| S&P Global | 금융 데이터 | 신용 평가, 시장 분석, 산업 리서치 |
| LSEG | 금융 데이터 | 실시간 시장 데이터, 뉴스, 기업 분석 |

각 커넥터의 연결 방법은 동일하다. Cowork 설정 > Connectors에서 원하는 서비스의 Connect 버튼을 클릭하고 인증을 완료하면 된다.

> **Tip**: 모든 커넥터를 한꺼번에 연결할 필요는 없다. 실제로 자주 쓰는 서비스만 연결하면 된다. 나중에 필요할 때 추가로 연결할 수 있다.

## 커넥터 없이도 가능한 것

외부 커넥터가 없어도 Cowork으로 할 수 있는 일은 매우 많다. 커넥터는 **필수가 아니라 선택**이다.

### 로컬 파일만으로 가능한 작업

| 작업 | 설명 |
|------|------|
| 문서 작성/편집 | Word, Excel, PowerPoint 등 오피스 파일 생성 및 편집 |
| 데이터 분석 | Excel, CSV 파일의 데이터를 읽고 분석 |
| 파일 정리 | 폴더 구조 정리, 파일 분류, 이름 변경 |
| 보고서 생성 | 데이터를 기반으로 보고서 작성 |
| 텍스트 변환 | 형식 변환, 번역, 요약, 톤 변경 |
| 이미지 설명 | 이미지 파일의 내용을 텍스트로 설명 |

### 커넥터를 쓰면 추가되는 것

커넥터는 Cowork의 활동 범위를 **외부 서비스로 확장**해준다. 로컬 파일과 외부 서비스를 조합하면 더 강력한 워크플로가 가능하다.

**조합 예시**

```
1. Gmail에서 이번 주 고객 문의 이메일을 검색해줘
2. 문의 내용을 유형별로 분류해서 Excel로 정리해줘 (로컬 저장)
3. 각 유형별 답변 템플릿을 만들어줘 (로컬 저장)
4. 답변 초안을 Gmail 초안으로 작성해줘
```

이 워크플로에서 1번과 4번은 커넥터가 필요하지만, 2번과 3번은 로컬 파일 작업이다. 커넥터와 로컬 작업이 자연스럽게 이어진다.

### 어떤 커넥터를 먼저 연결해야 할까

업무 유형에 따라 추천하는 우선순위가 다르다.

| 업무 유형 | 추천 커넥터 (1순위) | 추천 커넥터 (2순위) |
|-----------|---------------------|---------------------|
| 일반 사무직 | Gmail, Google Calendar | Google Drive |
| 마케팅/영업 | Gmail, Google Drive | Apollo, Outreach |
| 금융/투자 | FactSet, S&P Global | MSCI, LSEG |
| 법무/계약 | DocuSign | Harvey, LegalZoom |
| 콘텐츠 제작 | Google Drive | WordPress |

## 핵심 정리

**커넥터 기본 개념**
- 커넥터는 Cowork과 외부 서비스를 연결하는 다리다
- 설정 > Connectors에서 원클릭 + OAuth 인증으로 연결한다
- 최소 권한 원칙을 따르며, 위험한 작업(이메일 발송 등)은 사용자가 직접 수행한다

**효과적인 활용 원칙**
- 커넥터 없이도 로컬 파일만으로 많은 작업이 가능하다. 커넥터는 선택 사항이다
- 외부 서비스 작업도 [효과적인 지시 작성법](03-효과적인-지시-작성법.md)의 원칙이 동일하게 적용된다
- 복잡한 작업은 로컬 파일 작업과 커넥터 작업을 단계별로 나눠서 진행한다

**주의 사항**
- 이메일 발송, 일정 생성 등 외부에 영향을 미치는 작업은 반드시 결과를 확인한 뒤 실행한다
- 계약서 분석 같은 전문 영역은 Cowork의 결과를 참고 자료로 사용하고, 최종 판단은 전문가가 한다
- 모든 커넥터를 한꺼번에 연결할 필요 없이, 자주 쓰는 서비스부터 하나씩 연결한다
