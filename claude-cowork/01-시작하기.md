# Claude Cowork 시작하기

> **난이도**: 기초 | **선행 문서**: 없음 | **최초 작성**: 2026-04-13 | **마지막 수정**: 2026-04-13
>
> Claude Cowork의 설치부터 첫 작업까지, 비개발자를 위한 데스크톱 AI 어시스턴트 시작 가이드.

---

## Claude Cowork란?

Claude Cowork는 Anthropic이 만든 데스크톱 AI 어시스턴트다. Claude Desktop 앱 안에서 동작하며, 내 컴퓨터의 파일을 직접 읽고, 분석하고, 새로운 파일을 만들어주는 실행형 AI 도구다.

Anthropic의 Claude 제품군은 크게 세 가지로 나뉜다.

| 구분 | 한마디 정의 | 비유 |
|------|------------|------|
| **Claude Chat** | 사고 도구 | 똑똑한 대화 상대 — 질문하면 답해준다 |
| **Claude Code** | 구축 도구 | 개발자 옆에 앉은 시니어 엔지니어 — 코드를 직접 짠다 |
| **Claude Cowork** | 실행 도구 | 유능한 사무 보조 — 파일 정리부터 보고서 작성까지 직접 해준다 |

Chat은 "생각"을 도와주고, Code는 "개발"을 도와주고, Cowork는 "업무"를 도와준다. Cowork의 핵심은 대화로 끝나지 않고 실제 결과물(파일)이 나온다는 점이다.

### 누구를 위한 도구인가?

Cowork는 개발자가 아닌 사람을 위해 만들어졌다. 터미널이나 코드 편집기를 쓸 필요가 없다.

- **마케터**: 캠페인 데이터 분석, 보고서 자동 생성
- **기획자**: 기획서 초안 작성, 경쟁사 자료 정리
- **분석가**: 스프레드시트 데이터 처리, 차트 포함 리포트 생성
- **사무직 전반**: 파일 정리, 문서 변환, 반복 작업 자동화

요컨대 "컴퓨터로 문서 작업을 하는 사람"이라면 누구에게든 유용하다.

## Chat/Code와 뭐가 다를까?

같은 Claude지만, 어떤 형태로 쓰느냐에 따라 할 수 있는 일이 완전히 다르다.

| 항목 | Claude Chat | Claude Code | Claude Cowork |
|------|------------|-------------|---------------|
| **목적** | 질문과 대화 | 소프트웨어 개발 | 업무 실행 |
| **주 사용자** | 누구나 | 개발자 | 지식 노동자(비개발자 포함) |
| **인터페이스** | 웹 브라우저 (claude.ai) | 터미널 (CLI) | 데스크톱 앱 |
| **작업 방식** | 텍스트 주고받기 | 코드 읽기/쓰기/실행 | 파일 읽기/쓰기/생성 |
| **파일 접근** | 업로드한 파일만 | 프로젝트 폴더 전체 | 공유한 폴더의 파일 |
| **결과물** | 텍스트 답변 | 코드, 커밋, PR | Excel, Word, PPT, PDF 등 |
| **터미널 필요** | 아니오 | 예 | 아니오 |

가장 큰 차이는 **파일 접근 방식**이다. Chat은 파일을 하나씩 업로드해야 하지만, Cowork는 내 컴퓨터의 폴더를 공유하면 그 안의 파일을 자유롭게 읽고 쓴다. 업로드 버튼을 누를 필요가 없다.

## 설치와 설정

### 시스템 요구사항

Cowork를 사용하려면 아래 조건이 필요하다.

| 항목 | macOS | Windows |
|------|-------|---------|
| **OS 버전** | macOS 10.15 (Catalina) 이상 | Windows 10 이상 |
| **칩셋** | Apple Silicon (M1) 이상 | 제한 없음 |
| **RAM** | 8GB 이상 | 8GB 이상 |
| **디스크 여유 공간** | 10GB 이상 | 10GB 이상 |

Intel Mac에서는 사용할 수 없다. 2020년 이후 출시된 Mac이라면 대부분 Apple Silicon이다. 확인 방법: 화면 좌측 상단  메뉴 → "이 Mac에 관하여"에서 칩 항목을 확인한다.

### 구독 요금

Cowork는 유료 구독이 필요하다.

| 플랜 | 월 요금 | Cowork 사용 |
|------|---------|------------|
| Free (무료) | $0 | 사용 불가 |
| **Pro** | **$20** | **사용 가능** |
| **Max** | **$100~200** | **사용 가능 (더 많은 사용량)** |

이미 Claude Pro 구독 중이라면 추가 결제 없이 바로 쓸 수 있다.

### 설치 방법

1. **[claude.ai/download](https://claude.ai/download)** 에 접속한다
2. 운영체제에 맞는 설치 파일을 내려받는다
3. 설치 파일을 실행한다
   - macOS: `.dmg` 파일을 열고, Claude 아이콘을 Applications 폴더로 끌어다 놓는다
   - Windows: `.exe` 파일을 실행하고 안내를 따른다
4. Claude Desktop 앱을 실행한다
5. Anthropic 계정으로 로그인한다

설치가 끝나면 앱 하단에 "Cowork" 탭이 보인다. 터미널이나 명령줄 도구는 전혀 필요 없다. 웹 브라우저가 아닌 독립 실행형 앱에서 동작한다는 점을 기억하자.

## Global Instructions 설정

Cowork를 처음 쓸 때 가장 먼저 해야 할 일은 Global Instructions(전역 지침)를 설정하는 것이다. 이것은 Claude에게 "나는 이런 사람이고, 이런 방식으로 일해줘"라고 미리 알려두는 장치다.

새로 합류한 어시스턴트에게 첫날 이런 말을 하는 것과 같다.

> "나는 마케팅팀 소속이에요. 보고서는 항상 한국어로 쓰고, 표는 마크다운 말고 Excel 파일로 만들어주세요. 수치는 천 단위 쉼표를 넣어주세요."

### 설정 방법

1. Claude Desktop 앱을 연다
2. **Settings** (설정) 메뉴로 이동한다
3. **Cowork** 탭을 선택한다
4. **Global Instructions** 영역에 내용을 입력한다

### 좋은 Global Instructions 예시

```
나는 마케팅팀 소속이고, 보고서는 항상 한국어로 작성해주세요.
표는 마크다운 대신 Excel 파일(.xlsx)로 만들어주세요.
숫자는 천 단위 쉼표를 사용하고, 금액은 "원" 단위를 붙여주세요.
파일 이름은 항상 날짜를 앞에 붙여주세요 (예: 2026-04-13_월간보고서.xlsx).
설명은 간결하게 해주세요. 불필요한 인사말은 생략해도 됩니다.
```

### 나쁜 예 → 좋은 예

| 나쁜 예 | 문제 | 좋은 예 |
|---------|------|---------|
| "잘 해주세요" | 기준이 없다 | "보고서는 A4 한 장 분량으로 작성해주세요" |
| "알아서 해줘" | 선호를 모른다 | "표는 Excel로, 요약은 Word로 만들어주세요" |
| (아무것도 안 씀) | 매번 같은 말 반복 | 위의 예시처럼 작성 |

Global Instructions는 모든 대화에 자동으로 적용되므로, 한 번 잘 써두면 매번 반복해서 설명하지 않아도 된다.

## 첫 번째 작업 따라하기

설치와 설정이 끝났다면, 간단한 실습을 따라해보자. 파일이 어지럽게 쌓인 폴더를 Cowork에게 정리시키는 작업이다.

### 준비

1. 바탕화면이나 문서 폴더에 **"Cowork-연습"** 이라는 폴더를 만든다
2. 아무 파일이나 5~10개 복사해 넣는다 (PDF, 사진, 엑셀 등 섞어서)
3. 파일 이름도 제각각인 상태가 이상적이다

### 실행

1. Claude Desktop 앱에서 **Cowork** 탭을 연다
2. 방금 만든 **"Cowork-연습"** 폴더를 공유한다 (폴더를 앱 창에 끌어다 놓거나 폴더 선택 버튼 사용)
3. 아래 프롬프트를 입력한다

```
이 폴더에 있는 파일들을 정리해줘.

규칙:
- 파일 종류별로 하위 폴더를 만들어서 분류해줘 (문서, 이미지, 스프레드시트 등)
- 각 파일 이름 앞에 오늘 날짜(2026-04-13)를 붙여줘
- 정리가 끝나면 어떤 파일을 어디로 옮겼는지 목록을 보여줘
```

4. Claude가 계획을 세우고, 실행하고, 결과를 보여준다
5. 결과를 확인한다 — 폴더 안에 하위 폴더가 생기고, 파일이 분류되어 있을 것이다

### 실행 중 화면에서 볼 수 있는 것들

- Claude가 어떤 파일을 읽고 있는지 실시간으로 표시된다
- 파일을 이동하거나 이름을 변경할 때 확인을 요청할 수 있다
- 작업이 끝나면 요약 결과를 텍스트로 보여준다

처음이라 긴장될 수 있지만, 연습용 폴더에서 시작했으므로 원본 파일에는 영향이 없다. 안심하고 시도해보자.

## 작업 흐름 이해하기

Cowork의 작업 흐름은 네 단계로 반복된다.

```
사용자가 목표 설명 → Claude가 계획 수립 → 실행 (파일 읽기/쓰기) → 결과 확인
```

### 1단계: 사용자가 목표를 설명한다

자연어(일상 언어)로 원하는 것을 말한다. 프로그래밍 언어나 특별한 명령어를 배울 필요가 없다.

```
지난 분기 매출 데이터를 분석해서 월별 추이 차트가 포함된 보고서를 만들어줘
```

### 2단계: Claude가 계획을 수립한다

Claude는 요청을 분석하고, 어떤 순서로 작업할지 계획을 세운다. 이 과정이 화면에 표시되므로, Claude가 의도를 제대로 이해했는지 미리 확인할 수 있다.

### 3단계: 실행한다

계획에 따라 Claude가 직접 작업한다.

- 공유 폴더에서 파일을 읽는다
- 데이터를 분석한다
- 새로운 파일(Excel, Word, PPT, PDF 등)을 생성한다
- 기존 파일의 이름을 바꾸거나 폴더를 정리한다

이 과정에서 사용자가 하나하나 지시하지 않아도 된다. 목표를 주면 Claude가 자율적으로 실행한다. 다만 파일 삭제 같은 위험한 작업은 사전에 확인을 요청한다.

### 4단계: 결과를 확인한다

작업이 끝나면 Claude가 무엇을 했는지 요약해준다. 결과가 마음에 들지 않으면 추가 지시를 내릴 수 있다.

```
좋은데, 차트 색상을 회사 브랜드 컬러(파란색 #2563EB)로 바꿔줘
```

이 네 단계가 한 세션 안에서 계속 반복된다.

### 알아두면 좋은 점

- **세션 독립성**: 대화창을 닫으면 그 세션의 기억은 사라진다. 다음에 새 대화를 시작하면 이전 작업 내용을 기억하지 못한다. 중요한 지시사항은 Global Instructions에 넣어두자.
- **앱 실행 필수**: Cowork는 Claude Desktop 앱이 실행 중이어야 동작한다. 앱을 닫으면 작업이 중단된다.
- **로컬 파일 접근**: Cowork는 내 컴퓨터의 파일에 직접 접근한다. 파일을 인터넷에 업로드하는 것이 아니다. 다만 대화 내용은 Anthropic 서버를 통해 처리된다.
- **생성 가능한 파일 형식**: Excel(.xlsx), Word(.docx), PowerPoint(.pptx), PDF(.pdf) 등 일반적인 사무용 파일을 만들 수 있다.

## Cowork를 쓰면 좋은 상황, 안 맞는 상황

### 이런 작업에 잘 맞는다

| 작업 | 구체적 예시 |
|------|------------|
| 파일 정리 | 수백 개 파일을 날짜/유형별 폴더로 분류 |
| 데이터 분석 | 매출 스프레드시트에서 추이 파악, 차트 생성 |
| 문서 변환 | CSV 데이터를 Excel 보고서로, 텍스트를 PPT로 |
| 반복 작업 | 50개 파일의 이름을 일괄 변경 |
| 요약/추출 | 긴 PDF에서 핵심 조건 추출 |
| 보고서 생성 | 데이터에서 분석 보고서 자동 작성 |

### 이런 작업에는 맞지 않는다

| 작업 | 이유 | 대안 |
|------|------|------|
| 실시간 데이터 조회 | 인터넷 검색이 주 목적이면 Chat이 낫다 | Claude Chat |
| 코드 개발 | 코드 작성/실행/디버깅은 Code의 영역이다 | Claude Code |
| 장시간 자동화 | 앱을 계속 열어두어야 하므로 예약 작업엔 부적합 | 별도 자동화 도구 |
| 기밀 데이터 처리 | 대화 내용이 서버를 거치므로 민감 데이터 주의 | 사내 보안 정책 확인 |

## 핵심 정리

- Claude Cowork는 Claude Desktop 앱에서 동작하는 데스크톱 AI 어시스턴트로, 비개발자를 위한 실행형 도구다.
- Chat이 "대화"에, Code가 "개발"에 특화된 것처럼, Cowork는 "업무 실행"에 특화되어 있다.
- 설치는 [claude.ai/download](https://claude.ai/download)에서 앱을 내려받으면 된다. 터미널이나 CLI는 필요 없다.
- macOS는 Apple Silicon(M1) 이상, Windows는 Windows 10 이상이 필요하며, Pro($20/월) 이상 구독이 필요하다.
- Global Instructions를 설정하면 매 대화마다 같은 말을 반복하지 않아도 된다.
- 작업 흐름은 "목표 설명 → 계획 수립 → 실행 → 결과 확인"의 네 단계가 반복된다.
- 세션 간 기억이 유지되지 않으므로, 반복되는 선호사항은 Global Instructions에 넣어두자.
