# 효과적인 지시 작성법

> **난이도**: 기초~중급 | **선행 문서**: [파일 다루기](02-파일-다루기.md) | **최초 작성**: 2026-04-13 | **마지막 수정**: 2026-04-13
>
> Cowork에게 원하는 결과를 정확히 얻기 위한 지시 작성의 원칙과 실전 템플릿을 다룬다.

---

## 왜 지시 작성법이 중요한가

Cowork은 강력한 도구이지만, 결과물의 품질은 전적으로 지시의 품질에 달려 있다. 같은 도구라도 어떻게 요청하느냐에 따라 완전히 다른 결과가 나온다.

예를 들어 보자.

**막연한 지시**

```
이 폴더 정리해줘
```

이 요청을 받은 Cowork은 추측에 의존한다. "정리"가 이름순 정렬인지, 날짜별 분류인지, 중복 제거인지 알 수 없다. 결과가 매번 달라지고, 원하는 것과 다를 확률이 높다.

**구체적인 지시**

```
1. out/manifest.csv를 생성해서 모든 파일 목록을 기록해줘
2. .png 파일만 images/ 폴더로 월별(2026-01, 2026-02…) 하위 폴더를 만들어 이동해줘
3. 원본 파일은 덮어쓰지 말고 복사해줘
```

두 번째 지시는 무엇을(manifest.csv 생성, 이미지 이동), 어떻게(월별 폴더, 복사), 무엇을 하지 말아야 하는지(원본 덮어쓰기 금지)가 명확하다. Cowork은 추측 없이 정확히 실행한다.

> 핵심은 간단하다. **Cowork에게 더 구체적으로 말할수록, 원하는 결과에 더 가까워진다.**

## 좋은 지시의 다섯 가지 원칙

### 구체적으로 (Specific)

"무엇을 해야 하는지"를 최대한 명확하게 적는다. "잘 정리해줘"가 아니라, 정리의 기준과 방법을 말해준다.

| 막연한 표현 | 구체적인 표현 |
|---|---|
| 보고서 만들어줘 | A4 2페이지 분량의 월간 매출 보고서를 만들어줘 |
| 이 데이터 분석해줘 | 이 Excel의 B열(매출)과 D열(비용)을 비교해서 수익률을 계산해줘 |
| 파일 정리해줘 | .pdf 파일은 계약서/ 폴더로, .xlsx 파일은 데이터/ 폴더로 분류해줘 |

### 결과물 형식 지정 (Format)

원하는 결과물의 형태를 직접 지정한다. Excel인지, Word인지, PDF인지, 어떤 열(column)이 있어야 하는지, 어떤 섹션 구성인지를 말해준다.

```
결과를 Excel로 만들어줘.
열 구성: A열(고객명), B열(문의 일자), C열(문의 유형), D열(처리 상태)
시트 이름: "고객문의_4월"
```

형식을 지정하지 않으면 Cowork이 자체적으로 판단하는데, 그 판단이 당신의 기대와 다를 수 있다. "표로 만들어줘"보다 "Excel 파일로 만들어줘, 열은 이름/날짜/금액 세 개"가 훨씬 낫다.

### 제약 조건 명시 (Constraints)

하지 말아야 할 것, 지켜야 할 범위, 분량 제한 등을 명확히 적는다. 제약 조건이 없으면 Cowork이 과하게 하거나 부족하게 할 수 있다.

```
- 원본 파일은 삭제하지 마
- 한국어로만 작성해줘
- 분량은 A4 2페이지를 넘기지 마
- 외부 데이터는 사용하지 말고, 제공한 파일의 데이터만 사용해줘
```

> **Tip**: 제약 조건은 목록(bullet) 형태로 적으면 Cowork이 하나도 빠뜨리지 않고 따른다.

### 단계 분해 (Steps)

복잡한 작업은 한 번에 요청하지 말고 단계별로 나눈다. 번호를 매겨서 순서를 알려주면 Cowork이 각 단계를 차례대로 실행한다.

```
1. sales_data.xlsx를 읽어줘
2. 월별 매출 합계를 계산해줘
3. 매출이 가장 높은 달과 낮은 달을 찾아줘
4. 결과를 "월간매출분석.xlsx"로 저장해줘
```

단계를 나누면 두 가지 이점이 있다. 첫째, 중간 결과를 확인할 수 있다. 둘째, 특정 단계에서 문제가 생기면 해당 단계만 수정하면 된다.

### 예시 제공 (Examples)

원하는 결과물의 샘플을 보여주면 Cowork이 형식과 톤을 정확히 맞출 수 있다. 백 마디 설명보다 하나의 예시가 효과적이다.

```
아래 형식으로 고객 이메일 답변 초안을 만들어줘:

---
[고객명]님 안녕하세요,

[문의 내용에 대한 답변 1-2문장]

추가 문의 사항이 있으시면 언제든 연락 주세요.
감사합니다.
[회사명] 고객지원팀
---
```

## 나쁜 지시 vs 좋은 지시 모음

실무에서 자주 발생하는 상황별로, 나쁜 지시와 좋은 지시를 비교한다. 각 사례에서 왜 나쁜지, 왜 좋은지를 함께 설명한다.

### 파일 정리

**나쁜 예**

```
다운로드 폴더 정리해줘
```

> **문제점**: "정리"의 기준이 없다. 이름순? 유형별? 날짜별? 삭제해도 되는 건지도 불분명하다.

**좋은 예**

```
다운로드/ 폴더에서:
1. .pdf 파일은 문서/ 폴더로 이동
2. .jpg, .png 파일은 이미지/ 폴더로 이동
3. .xlsx, .csv 파일은 데이터/ 폴더로 이동
4. 나머지 파일은 기타/ 폴더로 이동
5. 원본은 삭제하지 말고 복사해줘
```

> **왜 좋은가**: 파일 유형별 분류 기준, 폴더 이름, 원본 보존 여부가 모두 명시되어 있다.

### 보고서 작성

**나쁜 예**

```
이 데이터로 보고서 만들어줘
```

> **문제점**: 보고서의 목적, 독자, 형식, 분량이 전혀 없다. 기술 보고서인지 경영 보고서인지도 알 수 없다.

**좋은 예**

```
sales_q1.xlsx 데이터를 기반으로 경영진 보고용 1분기 매출 보고서를 만들어줘.
- 형식: Word 문서
- 분량: A4 2페이지 이내
- 구성: 요약(5줄) → 채널별 매출 비교표 → 전분기 대비 증감율 → 핵심 인사이트 3개
- 숫자에는 천 단위 쉼표를 넣어줘 (예: 1,234,567원)
- 톤: 간결하고 객관적으로
```

> **왜 좋은가**: 독자(경영진), 형식(Word), 분량(2페이지), 구성(섹션 순서), 서식(천 단위 쉼표), 톤까지 지정했다.

### 데이터 추출

**나쁜 예**

```
이 Excel에서 중요한 데이터 뽑아줘
```

> **문제점**: "중요한"의 기준이 주관적이다. 어떤 열에서 어떤 조건으로 추출하는지 알 수 없다.

**좋은 예**

```
customers.xlsx에서 다음 조건에 맞는 데이터를 추출해줘:
- C열(가입일)이 2026년 1월 이후인 행만 필터링
- A열(이름), B열(이메일), E열(구매금액)만 포함
- 구매금액 내림차순으로 정렬
- 결과를 new_customers_2026.xlsx로 저장
```

> **왜 좋은가**: 필터 조건, 포함할 열, 정렬 기준, 저장 파일명이 모두 명확하다.

### 이메일 초안

**나쁜 예**

```
고객한테 이메일 써줘
```

> **문제점**: 어떤 고객에게, 무슨 목적으로, 어떤 톤으로 쓸지 전혀 없다.

**좋은 예**

```
배송 지연에 대해 고객에게 사과 이메일 초안을 작성해줘.
- 받는 사람: 프리미엄 등급 고객
- 상황: 주문 #4521, 예정일보다 3일 지연
- 포함할 내용: 사과, 지연 사유(물류센터 시스템 점검), 새 배송 예정일(4월 18일), 보상(10% 할인 쿠폰)
- 톤: 정중하되 진심 어린 사과가 느껴지도록
- 분량: 10줄 이내
```

> **왜 좋은가**: 상황, 포함 내용, 톤, 분량이 구체적이어서 바로 보낼 수 있는 수준의 초안이 나온다.

### 회의록 정리

**나쁜 예**

```
회의 내용 정리해줘
```

> **문제점**: 어떤 형식으로 정리할지, 무엇에 초점을 맞출지 없다.

**좋은 예**

```
meeting_0411.txt 회의 녹취록을 아래 형식으로 정리해줘:

## 회의 요약
- 일시/참석자/안건을 한 줄씩

## 주요 논의 사항
- 안건별로 2-3줄 요약

## 결정 사항
- 확정된 내용만 목록으로

## 액션 아이템
- 표 형식: 담당자 | 할 일 | 마감일

불필요한 잡담이나 인사말은 제외해줘.
```

> **왜 좋은가**: 섹션 구조, 각 섹션에 무엇을 넣을지, 제외할 내용까지 지정했다. 매번 같은 형식으로 결과가 나온다.

### 리서치 및 조사

**나쁜 예**

```
경쟁사 조사해줘
```

> **문제점**: 어떤 경쟁사를, 어떤 관점에서, 어떤 형태로 조사할지 없다.

**좋은 예**

```
competitors.xlsx에 나열된 5개 경쟁사에 대해 비교 분석표를 만들어줘.
- 비교 항목: 주요 제품, 가격대, 타겟 고객, 강점, 약점
- 형식: Excel 표
- 데이터 출처: 제공한 파일의 정보만 사용
- 마지막에 "우리 회사 대비 포지셔닝 요약"을 3줄로 추가해줘
```

> **왜 좋은가**: 비교 항목, 형식, 데이터 범위, 추가 요청이 구체적이다.

### 스프레드시트 가공

**나쁜 예**

```
이 Excel 좀 다듬어줘
```

> **문제점**: "다듬기"의 범위가 불분명하다. 서식? 수식? 데이터 정리?

**좋은 예**

```
budget_2026.xlsx를 다음과 같이 수정해줘:
1. B열~D열의 금액에 천 단위 쉼표 서식 적용
2. E열에 "전월 대비 증감율" 수식 추가 (소수점 첫째 자리까지)
3. 증감율이 마이너스인 셀은 빨간색으로 표시
4. 맨 아래에 각 열의 합계 행 추가
5. 시트 이름을 "2026_예산현황"으로 변경
```

> **왜 좋은가**: 서식, 수식, 조건부 서식, 합계, 시트 이름까지 단계별로 명시했다.

### 프레젠테이션 자료

**나쁜 예**

```
발표 자료 만들어줘
```

> **문제점**: 주제, 슬라이드 수, 청중, 디자인 방향이 전혀 없다.

**좋은 예**

```
신규 프로젝트 킥오프 발표 자료를 만들어줘.
- 형식: PowerPoint, 10슬라이드 이내
- 청중: 경영진 (비기술직)
- 슬라이드 구성:
  1. 표지 (프로젝트명, 날짜, 발표자)
  2. 프로젝트 배경 및 목적
  3. 현황 분석 (데이터 차트 포함)
  4-6. 핵심 전략 3가지 (각 1슬라이드)
  7. 예상 일정 (타임라인)
  8. 예산 요약
  9. 기대 효과
  10. Q&A
- 기초 데이터: project_plan.xlsx 참고
- 톤: 전문적이면서 간결하게, 슬라이드당 텍스트 5줄 이내
```

> **왜 좋은가**: 슬라이드별 구성, 청중, 톤, 분량 제한, 데이터 출처까지 완벽하게 지정했다.

## 멀티스텝 작업 분해하기

실무에서는 단순한 작업보다 여러 단계가 엮인 복잡한 작업이 더 많다. 이런 작업을 한 번에 요청하면 Cowork이 중간에 방향을 잃을 수 있다. 단계별로 분해하면 결과의 정확도가 크게 올라간다.

### 분해 원칙

1. **한 단계에 하나의 목표**만 담는다
2. **앞 단계의 결과물**이 다음 단계의 입력이 되도록 연결한다
3. **중간 확인 지점**을 만든다 (각 단계 결과를 확인하고 다음으로 넘어간다)

### 실전 예시: 월간 마케팅 보고서 만들기

하나의 큰 작업을 다섯 단계로 나눠보자.

**단계 1: 데이터 읽기**

```
marketing_april.xlsx를 읽고 어떤 데이터가 있는지 알려줘.
시트별로 열 이름과 데이터 건수를 정리해줘.
```

> Cowork이 데이터 구조를 요약해준다. 이 단계에서 기대한 데이터가 맞는지 확인한다.

**단계 2: 채널별 성과 비교표 만들기**

```
"캠페인" 시트에서 채널별(검색광고, SNS, 이메일, 디스플레이) 성과를 비교하는 표를 만들어줘.
항목: 노출수, 클릭수, 전환수, 비용, ROAS
```

> 표를 확인하고, 수정이 필요하면 이 단계에서 바로 요청한다.

**단계 3: 핵심 인사이트 추출**

```
위 비교표를 기반으로 핵심 인사이트 3개를 뽑아줘.
각 인사이트는 한 문장 요약 + 근거 데이터로 구성해줘.
```

**단계 4: 경영진용 요약 작성**

```
인사이트를 포함해서 경영진용 1페이지 요약을 만들어줘.
구성: 한 줄 결론 → 채널별 핵심 수치 표 → 인사이트 3개 → 다음 달 제안
```

**단계 5: 시각화 및 최종 파일 저장**

```
위 내용을 PowerPoint로 만들어줘.
5슬라이드 구성으로, 차트는 막대그래프로 넣어줘.
파일명: marketing_report_april_2026.pptx
```

이렇게 나누면 각 단계에서 결과를 확인하고 방향을 수정할 수 있다. 한 번에 모두 요청했다면 마지막에 가서야 문제를 발견하게 된다.

### 언제 한 번에 요청해도 되는가

모든 작업을 단계별로 나눠야 하는 건 아니다. 다음 조건을 모두 만족하면 한 번에 요청해도 괜찮다.

- 작업이 단순하고 명확하다 (예: 파일 유형별 분류)
- 중간 확인이 필요 없다 (예: 결과물 형식이 확실하다)
- 실패해도 되돌리기 쉽다 (예: 원본을 보존한다)

반대로, 결과물이 여러 사람에게 공유되거나, 판단이 개입되는 작업이라면 반드시 단계별로 나눈다.

---

## 결과물이 마음에 안 들 때

첫 결과가 완벽하지 않더라도 괜찮다. Cowork은 대화를 통해 결과물을 점진적으로 수정할 수 있다. 처음부터 다시 지시하는 것보다, 기존 결과물을 수정 요청하는 것이 훨씬 빠르다.

### 수정 요청 패턴

**형식 변경**

```
이 표를 가로 형식에서 세로 형식으로 바꿔줘
```

```
A열과 B열의 순서를 바꿔줘
```

**분량 조절**

```
요약이 너무 길어. 각 항목을 한 문장으로 줄여줘
```

```
3번 인사이트를 좀 더 상세하게 풀어줘
```

**톤 변경**

```
너무 딱딱해. 좀 더 친근한 톤으로 바꿔줘
```

```
경영진한테 보낼 거니까 좀 더 격식체로 바꿔줘
```

**내용 추가/삭제**

```
여기에 전년 동기 대비 증감율 열을 추가해줘
```

```
"기타" 카테고리는 빼줘. 주요 3개 채널만 남겨줘
```

### 실전 대화 흐름 예시

아래는 보고서를 반복 수정하는 실제 대화 흐름이다.

```
나: sales_q1.xlsx로 분기 매출 보고서를 만들어줘. 경영진용, A4 2페이지.

Cowork: [보고서 초안 생성]

나: 표가 너무 복잡해. 채널별 매출과 전분기 대비 증감율만 남기고 나머지 열은 빼줘.

Cowork: [표 간소화]

나: 좋아. 인사이트 부분에 "모바일 채널 매출이 처음으로 오프라인을 추월했다"는 점을 강조해줘.

Cowork: [인사이트 수정]

나: 마지막으로 이걸 Word 파일로 저장해줘. 파일명은 Q1_매출보고_v2.docx로.

Cowork: [파일 저장 완료]
```

핵심은 **한 번에 하나씩 수정을 요청**하는 것이다. "표도 바꾸고 인사이트도 고치고 파일 형식도 변경해줘"라고 한 번에 요청하면 일부가 누락될 수 있다.

## 자주 쓰는 프롬프트 템플릿

아래 템플릿을 복사해서 `[ ]` 안의 내용만 상황에 맞게 바꿔 쓰면 된다.

### 회의록 정리 템플릿

```
[파일명]을 아래 형식으로 정리해줘:

## 회의 개요
- 일시: [자동 추출]
- 참석자: [자동 추출]
- 안건: [자동 추출]

## 주요 논의 사항
- 안건별 2-3줄 요약

## 결정 사항
- 확정된 내용만 목록으로

## 액션 아이템
| 담당자 | 할 일 | 마감일 |
|--------|--------|--------|

## 다음 회의 안건
- 이번 회의에서 이월된 안건

잡담, 인사, 반복 발언은 제외해줘.
결과를 [파일명].xlsx로 저장해줘.
```

### 데이터 분석 보고서 템플릿

```
[데이터 파일명]을 분석해서 보고서를 만들어줘.

## 분석 목적
[예: 1분기 마케팅 채널별 ROI 비교]

## 분석 범위
- 기간: [예: 2026년 1~3월]
- 대상: [예: 검색광고, SNS, 이메일 3개 채널]
- 핵심 지표: [예: 비용, 전환수, ROAS]

## 결과물 형식
- 채널별 비교표 (Excel)
- 핵심 인사이트 [N]개
- 경영진용 한 줄 결론

## 제약 조건
- 제공한 데이터만 사용할 것
- 숫자는 천 단위 쉼표 포함
- [기타 조건]
```

### 이메일 초안 템플릿

```
아래 조건에 맞는 이메일 초안을 작성해줘.

- 받는 사람: [예: 파트너사 담당자]
- 목적: [예: 다음 분기 협업 제안]
- 포함할 핵심 내용:
  1. [내용 1]
  2. [내용 2]
  3. [내용 3]
- 톤: [예: 비즈니스 격식체, 친근하지만 전문적]
- 분량: [예: 15줄 이내]
- 첨부 파일 언급 여부: [예: proposal.pdf를 첨부했음을 언급]
```

### 파일 일괄 처리 템플릿

```
[폴더 경로]의 파일들을 일괄 처리해줘.

## 대상
- 파일 유형: [예: .xlsx]
- 조건: [예: 파일명에 "2026"이 포함된 파일만]

## 처리 내용
1. [작업 1: 예: 각 파일의 B열 합계를 계산]
2. [작업 2: 예: 결과를 summary.xlsx에 모아서 기록]
3. [작업 3: 예: 처리 완료된 파일을 done/ 폴더로 이동]

## 제약 조건
- 원본 파일을 수정하지 말 것
- 에러가 발생한 파일은 건너뛰고 목록만 알려줘
```

```

## 비교 항목

- Excel 비교표
- 마지막에 "종합 추천" 3줄 추가

## 제약 조건
- 사실 기반으로만 비교할 것 (추측 제외)
- [기타 조건]
```

## 핵심 정리

지시를 작성할 때 아래 다섯 가지를 점검한다.

**구체성**
- "정리해줘", "분석해줘" 같은 모호한 동사 대신 구체적인 행동을 적었는가?
- 어떤 파일을, 어떤 기준으로 처리하는지 명시했는가?

**형식**
- 결과물의 파일 유형(Excel, Word, PDF)을 지정했는가?
- 열 구성, 섹션 순서, 분량을 명시했는가?

**제약 조건**
- 하지 말아야 할 것(삭제 금지, 외부 데이터 사용 금지 등)을 적었는가?
- 분량, 언어, 톤 등의 제한을 넣었는가?

**단계 분해**
- 복잡한 작업은 번호 매긴 단계로 나눴는가?
- 중간에 확인할 수 있는 지점이 있는가?

**예시**
- 원하는 결과물의 샘플을 보여줬는가?
- 형식이나 톤이 중요한 경우 실제 예시를 포함했는가?
