## 1. 서브명령어

`codex <서브명령어>` 형태로 실행한다.

| 명령어 | 단축 | 설명 |
|--------|------|------|
| `codex` | — | 대화형 터미널 UI 세션 시작 |
| `codex exec` | `codex e` | 비대화형 단발성 실행 후 자동 종료 |
| `codex resume` | — | 이전 세션 이어서 실행 |
| `codex fork` | — | 이전 세션을 새 스레드로 분기 |
| `codex login` | — | ChatGPT 계정 또는 API 키로 인증 |
| `codex logout` | — | 저장된 인증 정보 제거 |
| `codex cloud` | — | 클라우드 작업(비동기 실행) 관리 |
| `codex mcp` | — | MCP 서버 설정 관리 |
| `codex app` | — | Codex 데스크톱 앱 실행 |
| `codex features` | — | 기능 플래그 활성화/비활성화 |

### 자주 쓰는 패턴

```bash
# 대화형 세션
codex

# 비대화형 자동 실행
codex exec "사용하지 않는 import를 모두 제거해줘" --full-auto

# 이전 세션 이어서 실행
codex resume

# 이전 세션을 새 스레드로 분기
codex fork
```

## 2. 글로벌 플래그

모든 서브명령어에서 공통으로 사용할 수 있는 플래그다.

| 플래그 | 단축 | 값 | 설명 |
|--------|------|-----|------|
| `--model` | `-m` | `string` | 사용할 모델 지정 |
| `--sandbox` | `-s` | `read-only` \| `workspace-write` \| `danger-full-access` | 샌드박스 정책 |
| `--ask-for-approval` | `-a` | `untrusted` \| `on-request` \| `never` | 승인 프롬프트 시점 |
| `--full-auto` | — | — | `on-request + workspace-write` 계열의 자동화 프리셋 |
| `--config` | `-c` | `key=value` | 설정값 일회성 재정의 (반복 가능) |
| `--cd` | `-C` | `path` | 작업 디렉터리 지정 |
| `--image` | `-i` | `path[,path...]` | 이미지 첨부 |
| `--profile` | `-p` | `string` | 설정 프로필 선택 |
| `--search` | — | — | 라이브 웹 검색 활성화 |
| `--oss` | — | — | 로컬 오픈소스 모델 사용 |
| `--remote` | — | `ws://host:port` | 원격 앱 서버 연결 |

### `--ask-for-approval` 값 설명

| 값 | 설명 |
|----|------|
| `untrusted` | 신뢰되지 않은 작업에만 승인 요청 (일반적인 기본값) |
| `on-request` | 에이전트가 요청할 때만 승인 |
| `never` | 승인 요청 없음 |

### `--full-auto` 프리셋

`--full-auto`는 보통 아래 설정 조합의 단축 플래그로 이해하면 된다.

```bash
# 아래 두 명령어는 동일하다
codex exec "작업" --full-auto
codex exec "작업" --ask-for-approval on-request --sandbox workspace-write
```

`--full-auto`가 곧 `danger-full-access`를 뜻하는 것은 아니다.

## 3. exec 전용 플래그

`codex exec` 서브명령어에서만 사용하는 플래그다.

| 플래그 | 단축 | 값 | 설명 |
|--------|------|-----|------|
| `--json` | — | — | 줄 구분 JSON 이벤트 형식으로 출력 |
| `--output-last-message` | `-o` | `path` | 최종 메시지를 파일에 저장 |
| `--ephemeral` | — | — | 세션 파일 저장 안 함 |
| `--color` | — | `always` \| `never` \| `auto` | ANSI 색상 제어 |
| `--skip-git-repo-check` | — | — | git 저장소 체크 건너뜀 |

```bash
# JSON 출력 + 최종 메시지 파일 저장
codex exec "분석해줘" --full-auto --json -o result.txt
```

## 4. resume / fork 플래그

| 플래그 | 값 | 설명 |
|--------|-----|------|
| `--last` | — | 선택 없이 최근 세션으로 바로 이동 |
| `--all` | — | 현재 디렉터리 외 세션도 포함해서 목록 표시 |

```bash
codex resume --last    # 바로 최근 세션 이어서 실행
codex fork --last      # 최근 세션을 새 스레드로 분기
```

## 5. 슬래시 명령어

대화형 세션 중 `/`로 시작하는 명령어다.

### 모델 및 설정

| 명령어 | 설명 |
|--------|------|
| `/model` | 활성 모델 변경 |
| `/fast` | 빠른 모드 토글 |
| `/personality` | 소통 스타일 변경 (친화적 / 실용적 / 없음) |

### 권한 및 보안

| 명령어 | 설명 |
|--------|------|
| `/permissions` | 승인 요구사항 조정 (Auto / Read Only 등) |
| `/sandbox-add-read-dir` | 샌드박스에 읽기 접근 디렉터리 추가 (Windows) |

### 작업 관리

| 명령어 | 설명 |
|--------|------|
| `/plan` | 계획 모드 전환 — 실행 전 계획 제안 |
| `/review` | 작업 트리 검토 요청 |
| `/diff` | git 변경사항 확인 |
| `/status` | 세션 설정 및 토큰 사용량 표시 |

### 대화 제어

| 명령어 | 설명 |
|--------|------|
| `/clear` | 터미널 초기화 및 새 채팅 시작 |
| `/new` | 같은 세션 내에서 새 대화 시작 |
| `/fork` | 현재 대화를 새 스레드로 분기 |
| `/resume` | 저장된 이전 세션 재개 |
| `/compact` | 대화를 요약해서 토큰 절약 |

### 도구 및 통합

| 명령어 | 설명 |
|--------|------|
| `/mcp` | 구성된 MCP 도구 목록 표시 |
| `/apps` | 앱(커넥터) 검색 및 삽입 |
| `/plugins` | 플러그인 검색 및 관리 |
| `/agent` | 활성 에이전트 스레드 전환 |
| `/init` | 현재 프로젝트에 AGENTS.md 생성 |

### 기타

| 명령어 | 설명 |
|--------|------|
| `/copy` | 최근 응답을 클립보드에 복사 |
| `/mention` | 파일 첨부 |
| `/ps` | 백그라운드 터미널 확인 |
| `/stop` | 백그라운드 터미널 중지 |
| `/debug-config` | 설정 계층 진단 |
| `/statusline` | 하단 상태 표시줄 항목 구성 |
| `/experimental` | 실험적 기능 토글 |
| `/feedback` | 피드백 전송 |
| `/logout` | 로그아웃 |
| `/quit` / `/exit` | CLI 종료 |

## 6. 자주 쓰는 조합

```bash
# 개발 중 — 안전하게 제안만 받기
codex -m gpt-5.4

# 빠른 반복 — 파일 변경은 자동, 셸은 확인
codex -m gpt-5.4-mini -s workspace-write -a untrusted

# CI/CD — 완전 자동화
codex exec "작업 설명" --full-auto

# 이미지 첨부해서 작업
codex -i screenshot.png

# 이전 작업 이어서 실행
codex resume --last
```
