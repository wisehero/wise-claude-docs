# Codex CLI 시작하기

> **난이도**: 기초 | **선행 문서**: 없음 | **최초 작성**: 2026-04-22 | **마지막 수정**: 2026-04-22
>
> OpenAI Codex CLI의 설치부터 첫 작업까지, 핵심 개념과 기본 사용법을 다룬다.

---

## 들어가며

Codex CLI는 OpenAI가 2025년 4월 공개한 오픈소스 터미널 기반 AI 코딩 에이전트다. Claude Code와 같은 계열의 도구이지만, OS 커널 수준의 샌드박스, 비동기 클라우드 실행, 완전 자율 모드 등 독자적인 특징을 갖는다. MIT 라이선스로 공개되어 있으며, `@openai/codex` npm 패키지로 배포된다.

---

## 1. 설치

### 시스템 요구사항

- Node.js 22 이상
- macOS, Linux (공식 지원) 또는 Windows WSL2 (실험적)
- 인터넷 연결 (API 호출)

### npm으로 설치

```bash
npm install -g @openai/codex
```

설치 후 버전을 확인한다.

```bash
codex --version
```

### Homebrew로 설치 (macOS/Linux)

```bash
brew install --cask codex
```

---

## 2. 인증

### ChatGPT 계정으로 로그인

처음 `codex`를 실행하면 브라우저 기반 로그인 프롬프트가 자동으로 나타난다. ChatGPT Plus 계정이 있으면 추가 설정 없이 바로 사용할 수 있다.

### API 키로 인증

API 키를 직접 사용하려면 환경 변수로 설정한다.

```bash
export OPENAI_API_KEY="sk-..."
```

영구 설정은 셸 설정 파일(`.zshrc`, `.bashrc` 등)에 추가한다.

```bash
echo 'export OPENAI_API_KEY="sk-..."' >> ~/.zshrc
source ~/.zshrc
```

CI/CD 환경에서는 파이프로 로그인한다.

```bash
printenv OPENAI_API_KEY | codex login --with-api-key
```

인증 정보는 기본적으로 `~/.codex/auth.json`에 저장된다. OS 키체인 사용 여부는 설정 파일에서 제어할 수 있다.

## 3. 기본 사용법

### 대화형 모드

인수 없이 실행하면 현재 디렉터리를 기준으로 대화형 세션이 시작된다.

```bash
codex
```

특정 경로를 지정할 수도 있다.

```bash
codex /path/to/project
```

세션이 시작되면 자연어로 작업을 입력한다.

```
> 이 파일에서 사용하지 않는 import를 모두 제거해줘
> 테스트를 작성해줘
> 이 함수의 성능을 개선해줘
```

### 세션 내 명령어

대화 중 슬래시 명령어로 동작을 제어한다. 자주 쓰는 것만 정리한다.

| 명령어 | 설명 |
|--------|------|
| `/model` | 사용 모델 변경 |
| `/permissions` | 승인 요구사항 조정 |
| `/plan` | 계획 모드 — 실행 전 계획 확인 |
| `/diff` | git 변경사항 확인 |
| `/compact` | 대화 요약으로 토큰 절약 |
| `/status` | 세션 설정 및 토큰 사용량 표시 |
| `/quit` | CLI 종료 |

전체 슬래시 명령어와 CLI 플래그는 [단축키와 명령어](08-단축키와-명령어.md)를 참고한다.

## 4. 승인 정책과 샌드박스

Codex CLI의 핵심 개념은 **승인 정책(`approval_policy`)**과 **샌드박스(`sandbox_mode`)**의 조합이다. 승인 정책은 언제 사용자 확인을 받을지를, 샌드박스는 에이전트가 실제로 어디까지 접근할 수 있을지를 정한다.

### 승인 정책

대표적인 값은 다음 세 가지다.

| 값 | 설명 |
|-----|------|
| `untrusted` | 신뢰되지 않은 작업에만 승인 요청. 일반적인 대화형 사용의 기본값 |
| `on-request` | 에이전트가 필요하다고 판단할 때 승인 요청 |
| `never` | 승인 요청 없음 |

```bash
codex --ask-for-approval untrusted
codex --ask-for-approval never
```

### 샌드박스 모드

대표적인 값은 다음 세 가지다.

| 값 | 설명 |
|-----|------|
| `read-only` | 읽기만 허용 |
| `workspace-write` | 작업 디렉터리 읽기/쓰기 허용 |
| `danger-full-access` | 제한 없음 |

```bash
codex --sandbox read-only
codex --sandbox workspace-write
```

### `--full-auto` 프리셋

`--full-auto`는 무제한 실행 모드가 아니라, 보통 아래 조합의 단축 프리셋으로 이해하면 된다.

```bash
codex --full-auto
# 대체로 다음과 같은 의미
codex --ask-for-approval on-request --sandbox workspace-write
```

**언제 사용하나**: 반복 작업 자동화, 비대화형 실행, CI/CD 파이프라인.

**주의**: `--full-auto`를 써도 `danger-full-access`가 자동으로 켜지는 것은 아니다.

## 5. 첫 작업 따라하기

다음 순서로 첫 번째 작업을 실행해보자.

**1단계: git 저장소 초기화**

```bash
mkdir my-project && cd my-project
git init
echo "# My Project" > README.md
git add . && git commit -m "init"
```

**2단계: Codex CLI 실행**

```bash
codex
```

**3단계: 작업 입력**

```
> README.md에 프로젝트 구조 섹션을 추가해줘. src/, tests/, docs/ 폴더가 있다고 가정하고.
```

**4단계: 변경 확인 및 승인**

Codex가 제안하는 변경 사항을 확인하고 `y`를 눌러 승인한다. 마음에 들지 않으면 `n`으로 거부하거나 수정 방향을 추가로 입력한다.

**5단계: 결과 검토**

```bash
git diff README.md
```

## 6. 핵심 정리

- Codex CLI는 `npm install -g @openai/codex`로 설치한다.
- 인증은 ChatGPT 계정 또는 `OPENAI_API_KEY` 환경 변수로 한다.
- 승인 정책(`untrusted`, `on-request`, `never`)과 샌드박스(`read-only`, `workspace-write`, `danger-full-access`)를 조합해 동작을 제어한다.
- `--full-auto`는 보통 `on-request + workspace-write` 프리셋으로 이해하면 된다.
- 자동화 작업 전에는 git 저장소를 준비해 두는 편이 안전하다.
- 세션 내에서 `/permissions`, `/model` 명령어로 설정을 바꿀 수 있다.
